# AI Project Context (Master Prompt)

## 1. Project Metadata
- **เป้าหมายหลัก**: พัฒนาและยกเครื่องระบบ AIA Financial Health Check & Planning Tool (Web Application) สำหรับวิเคราะห์สุขภาพทางการเงิน
- **ชื่อแบรนด์**: AIA
- **สไตล์ (Aesthetics)**: Apple-style Glassmorphism (Frosted glass effect, soft shadows, rounded corners, modern dynamic interfaces)
- **ค่าสี (Color Palette)**:
  - AIA Red: `#d21145` (Theme แดง: `#f8d9df`, `#fbebee`)
  - Navy Blue: `#0a75bb` (Theme น้ำเงิน: `#dbe9f8`, `#ecf2f9`)
  - Soft Grey/White: `#9ca3af`, `#d9d9d9`, `#ffffff`
  - Success Green: `#22c55e` (สำหรับ Checkbox/สถานะ)
- **Typography**: `Inter` หรือ `Kanit` เน้นการแสดงผลหัวข้อภาษาอังกฤษให้ชัดเจน และคำอธิบายภาษาไทยขนาดเล็กลง

## 2. Current Progress
- **✅ สรุปสถานะงานล่าสุดที่ทำเสร็จแล้ว (Overhaul Phase 3 - LAPS4 Flow)**:
  - **LAPS4 Flow Restructuring**: ปรับปรุงลำดับหน้าใหม่ทั้งหมดเป็น 15 สไลด์ (0-14) เพื่อรองรับการเล่าเรื่องแบบ "สารบัญ 4 แผนปกป้อง" (รายได้, เงินออม, ทรัพย์สิน, ใบปริญญา)
  - **Personal Profile & Income Early Sync**: ย้ายหน้าข้อมูลส่วนตัวมาไว้ต้นๆ เพื่อนำรายได้และอายุไปใช้คำนวณในหน้าต่อๆ ไปทันที
  - **Dynamic Asset & Liabilities**: ระบบคัดแยกทรัพย์สิน/หนี้สิน เพื่อหาตัวเลข "หนี้สินรวม" สำหรับวางแผนปกป้องทรัพย์สิน
  - **Inflation-Adjusted Retirement**: ระบบคำนวณเงินเฟ้อ Future Value ($FV = PV \times (1 + i)^n$) พร้อมปุ่มเลือกอัตรา 3%, 4%, 5%
  - **Welfare & Health Selection Redesign**: ตารางเปรียบเทียบสิทธิที่ปรับปรุงข้อมูล (สวัสดิการเดิม vs ส่วนตัว) และการเลือกแผน Economy/Business/First Class พร้อม CI 10-50 ล้าน
  - **Policy Audit Enhancement**: รองรับการเพิ่มหลายกรมธรรม์และระบุประเภทละเอียด (Endowment, Annuity, Unit-Linked) พร้อมระบบคำนวณยอดกู้สูงสุด 80%
  - **Agent Summary & Custom Selection**: หน้าจอสำหรับตัวแทนกรอกเบี้ยประกัน และหน้าสำหรับลูกค้าเลือกแผนเองอิสระ พร้อมระบบเช็คสัดส่วนเบี้ยไม่เกิน 15% ของรายได้ต่อปี
  - **Google Sheets Automated Integration**: จัดทำ `Code.gs` (Apps Script) ที่สามารถสร้าง Header คอลัมน์ได้เองอัตโนมัติเมื่อมีการส่งข้อมูลใหม่ๆ จาก Web App

- **⏳ สิ่งที่กำลังทำค้างอยู่ / ต้องปรับปรุงต่อ**:
  - เก็บรายละเอียด UX/UI ในส่วนของ Glassmorphism ให้ดูพรีเมียมยิ่งขึ้นในทกหน้าจอ (Mobile/Tablet/Desktop)
  - ตรวจสอบความถูกต้องของข้อมูลทั้งหมดที่ยิงเข้า Google Sheets หลังการปรับเปลี่ยน Payload ครั้งใหญ่
  - รอการปรับปรุงเพิ่มเติมในจุดอื่นๆ ตามที่ผู้ใช้แจ้งว่ามีแผนจะปรับต่อ

## 3. Technical Constraints & Rules
- **การจัดการ State/UI**: โครงสร้างเป็น Single Page App แบบ Vanilla JS สร้าง slide ในไฟล์ `app.js` ผ่าน template literal
- **การจัดการ Number Format**: ทุกครั้งที่คำนวณหรือแสดงผลตัวเลขเงิน ต้องใช้ฟังก์ชัน `fmt()` หรือใส่ลูกน้ำ (`toLocaleString('en-US')`) เสมอ
- **Google Sheets API**: ใช้ `fetch` แบบ `method: 'POST'` ร่วมกับ `mode: 'no-cors'` เพื่อส่งข้อมูล JSON ไปยัง Apps Script
- **Responsiveness**: รองรับอุปกรณ์ 3 แบบ (Laptop, iPad, Phone) ควบคุมผ่าน `platform-toggle`
- **Slide Setup**: อัปเดต `TOTAL_SLIDES = 15` ใน `engine.js` และ mapping slide logic ใน `SLIDE_PLAN_MAP`
