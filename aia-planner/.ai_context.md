## 3. Technical Constraints & Rules
- **การจัดการ State/UI**: โครงสร้างเป็น Single Page App (Vanilla JS) สร้าง slide ในไฟล์ `app.js`
- **Slide Setup**: ปัจจุบันใช้ `TOTAL_SLIDES = 14` (Slide 0-13)
- **Input Logic**: ใช้ `type="text" inputmode="numeric"` ร่วมกับ `formatNumberInput()` เพื่อให้ผู้ใช้กรอกตัวเลขจำนวนมากได้โดยไม่มีข้อจำกัดของเบราว์เซอร์
- **Cache Management**: ต้องระบุ version query string ใน `index.html` เมื่อมีการอัปเดตไฟล์ JS หลัก
- **Google Sheets API**: ใช้ Apps Script `doPost` รองรับ Dynamic Header และ `doGet` สำหรับ Verification
