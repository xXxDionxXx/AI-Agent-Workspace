# AI Project Context (Master Prompt)

## 1. Project Metadata
- **เป้าหมายหลัก**: พัฒนาและยกเครื่องระบบ AIA Financial Health Check & Planning Tool (Web Application) สำหรับวิเคราะห์สุขภาพทางการเงิน
- **ชื่อแบรนด์**: AIA
- **สไตล์ (Aesthetics)**: Apple-style Glassmorphism (Frosted glass effect, soft shadows, rounded corners, modern dynamic interfaces)
- **ค่าสี (Color Palette)**:
  - AIA Red: `#d21145` (Theme แดง: `#f8d9df`, `#fbebee`)
  - Navy Blue: `#0a75bb` (Theme น้ำเงิน: `#dbe9f8`, `#ecf2f9`)
  - Soft Grey/White: `#9ca3af`, `#d9d9d9`, `#ffffff`
  - Success Green: `#22c55e` (สำหรับ Checkbox/สถานะ)
- **Typography**: `Inter` หรือ `Kanit` (ปัจจุบันใช้ผสมผสาน IBM Plex Sans Thai และ Inter) เน้นการแสดงผลหัวข้อภาษาอังกฤษให้ชัดเจน และคำอธิบายภาษาไทยขนาดเล็กลง

## 2. Current Progress
- **✅ สรุปสถานะงานล่าสุดที่ทำเสร็จแล้ว**:
  - **3D Isometric Pyramid**: ปรับปรุง UI สามเหลี่ยมเป็นแบบ 3 มิติสมจริง (Isometric Stack) แบ่งสีชัดเจน (Red/Yellow/Green) พร้อม Cap ด้านบน
  - **Family/Single Toggle**: ระบบสลับโหมดครอบครัว/โสด ที่เปลี่ยนคำเรียกและเป้าหมาย (ค่าเทอมลูก ↔ ดูแลพ่อแม่) ทั่วทั้งแอปอัตโนมัติ
  - **Welfare Comparison**: ตารางเปรียบเทียบสิทธิรักษาพยาบาล 4 รูปแบบ (บัตรทอง, ประกันสังคม, ข้าราชการ, ประกันส่วนตัว) แบบละเอียด
  - **Health Plan Selection**: ระบบเลือกแผนสุขภาพแบบการ์ด (Economy, Business, First Class) เชื่อมโยงกับระดับโรงพยาบาลที่เลือก
  - **Comprehensive Tax Calculator**: ระบบคำนวณภาษีเต็มรูปแบบ รองรับรายได้ทุกประเภท, ค่าลดหย่อนทุกหมวด, และเครดิตภาษีเงินปันผล พร้อมสรุปผลประหยัดแบบ Real-time
  - **Policy Audit & Dashboard**: เพิ่มสไลด์ (14, 15) สำหรับกรอกกรมธรรม์เดิมที่มีอยู่ พร้อม Dashboard สรุปความคุ้มครองรวมและ Gap Analysis (ทุนชีวิตที่ขาด)
  - **Google Sheets Integration**: อัปเดต Payload ให้ส่งข้อมูลครบถ้วนทุก Field (Tax, Education, Policies, Welfare, Risks) ไปยัง Google Sheets
  - **Slide Structure**: ปรับปรุงจำนวนหน้าเป็น 17 หน้า (TOTAL_SLIDES = 17) เพื่อรองรับฟีเจอร์ที่เพิ่มขึ้น
- **⏳ สิ่งที่กำลังทำค้างอยู่**:
  - ตรวจสอบความถูกต้องของ UI บน Mobile (Phone Mode) หลังการปรับปรุง Pyramid 3D
  - รอการทดสอบการส่งข้อมูลเข้า Google Sheets จากผู้ใช้ในหน้างานจริง

## 3. Technical Constraints & Rules
- **การจัดการ State/UI**: โครงสร้างเป็น Single Page App แบบ Vanilla JS สร้าง slide ในไฟล์ `app.js` ผ่าน template literal
- **การจัดการ Number Format**: ทุกครั้งที่คำนวณหรือแสดงผลตัวเลขเงิน ต้องใช้ฟังก์ชัน `fmt()` หรือใส่ลูกน้ำ (`toLocaleString('en-US')`) เสมอ
- **Google Sheets API**: ใช้ `fetch` แบบ `method: 'POST'` ร่วมกับ `mode: 'no-cors'` เพื่อแก้ปัญหา CORS (จำกัดการอ่าน response กลับมา)
- **Responsiveness**: รองรับอุปกรณ์ 3 แบบ (Laptop, iPad, Phone) ควบคุมผ่าน `platform-toggle` ควบคุม class ที่ `<body>`
- **การแก้ไขไฟล์ข้อมูล**: 
  - สไตล์หลักอยู่ที่ `style.css`
  - โลจิกทั้งหมดและโครงสร้างหน้าตาแต่ละ Slide รวมอยู่ใน `app.js` (อัปเดตเลข `TOTAL_SLIDES = 17` ใน `engine.js` แล้ว)
  - ข้อมูลคงที่ (Tiers, Products, Tax Brackets, Welfare) อยู่ใน `data.js`
