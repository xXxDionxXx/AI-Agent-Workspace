# AI Project Context (Master Prompt)

## 1. Project Metadata
- **เป้าหมายหลัก**: พัฒนาและยกเครื่องระบบ AIA Financial Health Check & Planning Tool (Web Application) สำหรับวิเคราะห์สุขภาพทางการเงิน
- **ชื่อแบรนด์**: AIA
- **สไตล์ (Aesthetics)**: Apple-style Glassmorphism (Frosted glass effect, soft shadows, rounded corners, modern dynamic interfaces)
- **ค่าสี (Color Palette)**:
  - AIA Red: `#d21145` (Theme แดง: `#f8d9df`, `#fbebee`)
  - Navy Blue: `#0a75bb` (Theme น้ำเงิน: `#dbe9f8`, `#ecf2f9`)
  - Soft Grey/White: `#9ca3af`, `#d9d9d9`, `#ffffff`
  - Success Green: `#22c55e` (สำหรับ Checkbox/สถานะ)
- **Typography**: `Inter` หรือ `Kanit` (ปัจจุบันใช้ผสมผสาน IBM Plex Sans Thai และ Inter) เน้นการแสดงผลหัวข้อภาษาอังกฤษให้ชัดเจน และคำอธิบายภาษาไทยขนาดเล็กลง

## 2. Current Progress
- **✅ สรุปสถานะงานล่าสุดที่ทำเสร็จแล้ว**:
  - สร้าง UI แบบ "Financial Pyramid" (สไตล์ Glassmorphism) แบ่งเป็น 3 ชั้น (Investment, Saving, Protection) พร้อมแถบวางแผนภาษี (Tax Planning)
  - จัดเรียงลำดับหน้าจอใหม่ทั้งหมด 15 หน้า (Slides 0-14) เพื่อให้โฟลว์ลื่นไหลขึ้น
  - เพิ่มหน้า INVESTMENT สำหรับรับยอดเงินลงทุนรวม
  - ปรับปรุงการคำนวณ Education โดยรับจำนวนปีที่เรียน แล้วนำไปคูณกับเรทค่าเทอม (ช่วงราคา)
  - นำข้อมูล EXPENSES เดิมมาเปลี่ยนเป็น "กองทุนมรดก" (Legacy) (บ้าน, คอนโด, รถยนต์)
  - รวมหน้า Protection และ Income เข้าด้วยกัน พร้อมสร้างระบบคำนวณเงินแนะนำ (TIP boxes) ให้แปรผันตามรายได้ลูกค้า
  - ผูกข้อมูลจากปิรามิดมาสร้างเครื่องหมาย ✅ ในหน้า Recommended Plan (ECONOMY, BUSINESS, FIRST CLASS)
  - อัปเดตกฎ 15% (15% Rule) สำหรับเงินทุนความคุ้มครองในหน้าสุดท้าย
  - แก้บั๊ก Google Sheets `Failed to fetch` โดยเปลี่ยน Fetch API เป็น `mode: 'no-cors'`
- **⏳ สิ่งที่กำลังทำค้างอยู่**:
  - รอฝั่งผู้ใช้ (User) ทดสอบการเชื่อมต่อ Google Sheets ในสภาพแวดล้อมจริง
  - ปรับปรุง/ขัดเกลา UI เพิ่มเติมหากพบจุดที่แสดงผลไม่สมบูรณ์ในอุปกรณ์ขนาดต่างๆ

## 3. Technical Constraints & Rules
- **การจัดการ State/UI**: โครงสร้างเป็น Single Page App แบบ Vanilla JS สร้าง slide ในไฟล์ `app.js` ผ่าน template literal
- **การจัดการ Number Format**: ทุกครั้งที่คำนวณหรือแสดงผลตัวเลขเงิน ต้องใช้ฟังก์ชัน `fmt()` หรือใส่ลูกน้ำ (`toLocaleString('en-US')`) เสมอ
- **Google Sheets API**: ใช้ `fetch` แบบ `method: 'POST'` ร่วมกับ `mode: 'no-cors'` เพื่อแก้ปัญหา CORS (จำกัดการอ่าน response กลับมา)
- **Responsiveness**: รองรับอุปกรณ์ 3 แบบ (Laptop, iPad, Phone) ควบคุมผ่าน `platform-toggle` ควบคุม class ที่ `<body>`
- **การแก้ไขไฟล์ข้อมูล**: 
  - สไตล์หลักอยู่ที่ `style.css`
  - โลจิกทั้งหมดและโครงสร้างหน้าตาแต่ละ Slide รวมอยู่ใน `app.js` (ต้องอัปเดตเลข `TOTAL_SLIDES` ใน `engine.js` หากมีการเพิ่ม/ลดหน้า)
  - ข้อมูลคงที่ (Tiers, Products) อยู่ใน `data.js`
