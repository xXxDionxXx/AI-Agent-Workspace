## 3. Technical Constraints & Rules
- **การจัดการ State/UI**: โครงสร้างเป็น Single Page App (Vanilla JS) สร้าง slide ในไฟล์ `app.js`
- **Slide Setup**: ปัจจุบันใช้ `TOTAL_SLIDES = 15`
- **Submission**: ใช้ `fetch` v2.1 แบบ `no-cors` พร้อม `application/x-www-form-urlencoded` เพื่อเสถียรภาพสูงสุดจาก Local File
- **Apps Script**: ต้อง Deploy เป็น "Web App", Version "New Version", และ Access "Anyone"

## 6. AI Skill: Finance Expert
- **Data Handling & Computation:**
  - ใช้ประเภทข้อมูลที่มีความแม่นยำสูงสำหรับการคำนวณทางการเงิน (ใน JavaScript ควรระมัดระวังเรื่อง Floating-point arithmetic เสมอ เช่น `0.1 + 0.2` ถ้าจำเป็นควรปัดเศษหรือคูณ 100 ก่อนคำนวณ)
  - เก็บและจัดการค่าจำนวนเงินในหน่วยที่เล็กที่สุด (เช่น สตางค์) เพื่อความแม่นยำ
  - ใช้ฟังก์ชัน `fmt()` หรือหลักการ `toLocaleString()` ในการนำเสนอตัวเลขให้ลูกค้าดูเสมอ
- **Security & Validation:**
  - ห้ามเก็บบันทึกข้อมูลส่วนตัวและข้อมูลทางการเงินที่อ่อนไหวแบบไม่เข้ารหัส (ในบริบทของเราคือต้องระวังการส่งข้อมูลลูกค้า)
  - ใส่ใจเรื่อง Idempotency และ Audit Trails ในการทำธุรกรรม
- **Financial Calculations:**
  - มีความเชี่ยวชาญการคำนวณ Time Value of Money (TVM), Compound Interest, Loan Amortization และ Inflation ($FV = PV \times (1 + i)^n$)
  - การคำนวณความเสี่ยง และ Compliance ต่างๆ ที่เกี่ยวข้องกับการเงิน
