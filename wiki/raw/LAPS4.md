## **4 Rules — กฎที่ห้ามลืม**

| ⚡ Rule 1: Money Loves Speed เมื่อได้ Lead มาแล้ว ต้องติดต่อกลับภายใน 1 นาที (หรือเร็วที่สุด) ความไวคือการให้เกียรติความสนใจของลูกค้า — ยิ่งรอนาน โอกาสยิ่งเย็นลง |
| :---- |

| 🚫 Rule 2: No Stagnation ถ้าตัวเลข L หรือ A ตก ห้ามข้ามไปทำ S ให้กลับไปแก้ที่ต้นท่อ (Leads) ทันที ปัญหายอดขายส่วนใหญ่คือปัญหา Lead ไม่ใช่ปัญหา Closing |
| :---- |

| 📅 Rule 3: Consistency Over Intensity เข้าพบลูกค้า 3 คนทุกสัปดาห์ตลอดทั้งปี ดีกว่าวิ่งหาลูกค้า 20 คนในอาทิตย์เดียวแล้วหายไป 2 เดือน จังหวะสร้างความมั่นใจ ความมั่นใจสร้างยอดขาย |
| :---- |

| 📊 Rule 4: Data-Driven Improvement ใช้ AI วิเคราะห์ Transcript การคุยเสมอ เพื่อหาจุดอ่อนใน 'Golf Bag' ของเรา ทุกการเจอลูกค้าคือข้อมูลที่รอนำไปพัฒนา |

## **2.1 Referral System — ระบบขอรายชื่อใหม่**

Timing ที่ดีที่สุด: (1) ทันทีหลังลูกค้าตัดสินใจเซ็น (2) หลังลูกค้าได้รับการ Claim สำเร็จครั้งแรก

| 🎁 Referral Script 'ของเยี่ยมไข้' นิก: "พี่ครับ... ปกติถ้าเพื่อนสนิทพี่ป่วย พี่เอาอะไรไปเยี่ยมครับ?" — หยุดรอ — ให้เขาตอบ — ลูกค้า: "ก็กระเช้าผลไม้บ้าง หรือไม่ก็ซื้อของฝากไป" นิก: "ใช่เลยครับพี่ แต่พี่เห็นด้วยไหมครับว่า 'กำลังใจ ไม่ยิ่งใหญ่เท่ากำลังเงิน'?" — หยุดรอ — ให้เขาพยักหน้าหรือตอบตกลง — นิก: "จะดีกว่าไหมครับ ถ้าพี่แนะนำให้นิกรู้จักเพื่อนพี่คนนั้นในวันที่เขายังแข็งแรง เพื่อให้นิกเอา 'เงินบริษัท' ไปเตรียมไว้ให้เขาในวันที่เขาจำเป็น แทนที่เขาจะต้องควักเงินเก็บทั้งชีวิตมาจ่ายเอง" — หยุด 3 วิ — ให้ภาพในหัวเขาเกิดขึ้น — นิก: "พี่พอนึกออกไหมครับว่าเพื่อนคนไหนที่พี่รักและอยากให้เขามีสวัสดิการดีๆ แบบพี่?" — หยุด 8-10 วิ — ห้ามพูดแทรก ให้เขาคิดอย่างเต็มที่ — |

## **3.1 โครงสร้างการโทรนัด — 6 Steps**

| Step | ชื่อ | เป้าหมาย | เวลา |
| ----- | ----- | ----- | ----- |
| 1 | Name | แนะนำตัว — ให้เขารู้ว่าคุยกับใคร | 5 วิ |
| 2 | Ask Permission | ขอเวลา 1-2 นาที — ลดการ์ดทันที | 5 วิ |
| 3 | Reaffirm Relevance | บอกที่มา — ทำไมถึงโทรหาเขา | 10 วิ |
| 4 | Hook Pitch | MANHA Check \+ บอกว่าช่วยอะไรได้ | 30-45 วิ |
| 5 | Low Pressure Promise | ยืนยันว่าปฏิเสธได้ทันที | 10 วิ |
| 6 | Commitment | ปิดด้วย 2 ทางเลือก | 15 วิ |

## **3.2 บทโทรนัดเต็ม — กลุ่ม A (สนิท)**

| 📱 Line Message — ส่งก่อนโทร (กลุ่ม A) นิก: "สวัสดีครับพี่ \[ชื่อ\] 😊 นิกนะครับ ช่วงนี้เป็นยังไงบ้างครับ?" นิก: "ว่างๆ นิกอยากโทรคุยด้วยซักครู่นึงได้ไหมครับ? มีอัปเดตชีวิตอยากเล่าให้ฟัง" — รอให้เขาตอบก่อน — ถ้าตอบว่าโทรได้ ให้โทรเลย — |
| :---- |

| 📞 บทโทรศัพท์เต็ม — กลุ่ม A นิก: "สวัสดีครับพี่ \[ชื่อ\] นิกนะครับ รบกวนเวลาสัก 1-2 นาที พี่พอสะดวกคุยไหมครับ?" — หยุดรอ — ให้เขาตอบ — ลูกค้า: "ได้เลยครับ / อยู่ครับ ว่าไงดี" นิก: "ขอบคุณครับพี่ เป็นไงบ้างครับช่วงนี้ \[ถามเรื่องงาน/ครอบครัว/สิ่งที่เห็นใน Social สั้นๆ\]" — หยุดรอ — ฟัง Small Talk 1-2 ประโยค — นิก: "ดีเลยครับพี่ ที่นิกทักมาวันนี้นอกจากจะคิดถึงแล้ว พอดีนิกมีเรื่องจะมาอัปเดตชีวิตนิดนึงครับ ตอนนี้นิกขยับมาทำงานด้าน 'ที่ปรึกษาทางการเงินและตัวแทนประกันชีวิต' ที่ AIA เต็มตัวแล้วครับ" — หยุด 2 วิ — นิก: "พี่พอจะเคยคุยหรือมีที่ปรึกษามาช่วยดูแลเรื่องการวางแผนแล้วหรือยังครับ?" — MANHA Check — หยุดรอ — |

| 📞 บทโทร Referral เต็ม นิก: "สวัสดีครับ ขอโทรหาคุณ\[ชื่อลูกค้า\]ได้เลยไหมครับ? นิกนะครับ รบกวนเวลาสัก 1-2 นาที พี่พอสะดวกคุยไหมครับ?" — หยุดรอ — ลูกค้า: "ได้เลยครับ" นิก: "ขอบคุณครับพี่ พอดีนิกได้เบอร์พี่มาจากพี่\[ชื่อผู้แนะนำ\]ครับ เขาบอกว่าพี่\[ชื่อลูกค้า\]กำลัง\[ระบุ Life Event\] พี่\[ชื่อผู้แนะนำ\]เลยแนะนำให้นิกทักมาทำความรู้จักครับ" — หยุด 2 วิ — ให้เขา Connect ชื่อผู้แนะนำ — นิก: "ตอนนี้นิกทำงานด้านที่ปรึกษาทางการเงินและตัวแทนประกัน AIA ครับ ไม่ทราบว่าพี่พอจะมีที่ปรึกษาดูแลเรื่องแผนส่วนตัวอยู่แล้วหรือยังครับ?" — หยุดรอ — MANHA Check — |

## **3.5 Objection Handling — 6 ข้อโต้แย้งการโทรนัด**

| ❌ OBJ 4: 'อย่ามาขายนะ / ไม่อยากทำเพิ่มแล้ว' Feel: เข้าใจความกังวลของพี่เลยครับ พี่ไม่อยากมีความกดดันเรื่องต้องซื้ออะไรเพิ่มตอนนี้ใช่ไหมครับ Felt: ลูกค้าคนสำคัญของนิกหลายท่านก็เคยรู้สึกกังวลแบบนี้ครับ Found: แต่จริงๆ งานของนิกคือการส่งมอบข้อมูลครับ ถ้าพี่ดูสรุปแล้วรู้สึกว่ายังไม่จำเป็น พี่ปฏิเสธนิกได้ทันทีเลยครับ Close: นิกขอเวลาสั้นๆ 15 นาที ไปส่งเอกสารสรุปสิทธิ์สั้นๆ ครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |

| :---- |

## **3.7 Student to Parent Bridge — เพื่อนสู่ที่ปรึกษา (ใหม่)**

| 🎓 บทนี้สำหรับใคร? สำหรับตัวแทนที่เป็นนักศึกษาหรือวัยรุ่น ที่ต้องการใช้เพื่อนเป็นสะพานในการนัดหมายผู้ปกครอง เป้าหมายหลัก: เปลี่ยนสถานะจาก 'เพื่อน' เป็น 'ที่ปรึกษา' ก่อน แล้วค่อยต่อยอดไปหาครอบครัวเพื่อน กุญแจสำคัญ: ต้องให้เพื่อน 'เห็นคุณค่า' ของงานเราก่อน ไม่ใช่แค่ขอให้ช่วยบอกพ่อแม่ |

### **ขั้นตอนที่ 1 — เปลี่ยนสถานะกับเพื่อน**

| 💡 Mindset ก่อนคุยกับเพื่อน อย่าทำตัวเหมือน 'ขอความช่วยเหลือ' — ทำตัวเหมือน 'แบ่งปันโอกาส' ให้ครอบครัวเพื่อน เพื่อนจะยินดีช่วยเมื่อเขา 'เข้าใจ' ว่าสิ่งที่เราทำมีคุณค่าจริง ไม่ใช่แค่ขายของ ใช้ความเป็นเพื่อนให้เป็นประโยชน์ — เพื่อนพูดกับพ่อแม่ได้มีน้ำหนักกว่าคนแปลกหน้า 100% |
| :---- |

| 💬 บทคุยกับเพื่อนสนิท — เปิดเรื่องงานใหม่ นิก: "เฮ้ \[ชื่อเพื่อน\] ขอคุยด้วยนิดนึงได้มั้ย? ไม่นานหรอก 5 นาทีพอ" — รอให้เพื่อนพร้อม — นิก: "นิกทำงานที่ AIA มาสักพักแล้ว และเริ่มเข้าใจแล้วว่ามันไม่ใช่แค่การขายประกัน มันคือการวางแผนการเงินให้ครอบครัวคนจริงๆ" — หยุด 1 วิ — นิก: "เห็นข่าวไหมช่วงนี้ที่มีคนป่วยหนักแล้วครอบครัวล่มสลายเพราะไม่มีอะไรรองรับเลย? นิกเห็นเคสแบบนี้บ่อยมากในงาน" — หยุดรอให้เพื่อนแสดงความเห็น — เพื่อน: "อ๋อ เห็นบ้าง / ได้ยินบ้าง" นิก: "นั่นแหละ งานของนิกคือไปช่วยให้ครอบครัวคนไม่ต้องเจอสถานการณ์แบบนั้น นิกอยากขอความช่วยเหลือจากแกหน่อยนึงได้มั้ย?" |
| :---- |

### **ขั้นตอนที่ 2 — เปิดเผยผลกระทบ (Emotional Bridge)**

| ❤️ บทพูดเรื่องผลกระทบต่อครอบครัว นิก: "\[ชื่อเพื่อน\] แกเคยคิดบ้างมั้ยว่า ถ้าวันหนึ่งพ่อหรือแม่แกเกิดอะไรขึ้น แบบไม่มีใครคาดคิด ชีวิตของแกและที่บ้านจะเปลี่ยนไปยังไง?" — หยุด 2 วิ — ให้เพื่อนคิด — เพื่อน: "ก็... คงลำบากนะ" นิก: "ใช่เลย แกรู้จักดีกว่านิกว่าความฝันของแกคืออะไร เรียนต่อ ทำงานดีๆ ดูแลครอบครัว แต่ทุกอย่างนั้นมันตั้งอยู่บนเงื่อนไขที่ว่า เสาหลักของบ้านต้องยังอยู่และยังทำงานได้" — หยุด 2 วิ — นิก: "ถ้าเสาหลักหักวันนี้ แล้วไม่มีอะไรรองรับเลย ไม่ใช่แค่ครอบครัวที่ลำบาก แต่ความฝันของแกก็ต้องหยุดไปด้วย ไม่ว่าจะเป็นเรื่องเรียน เรื่องอนาคต หรือสิ่งที่แกตั้งใจไว้" — หยุด 3 วิ — ให้ภาพนั้นนั่งในหัวเพื่อน — นิก: "นิกไม่ได้พูดเพื่อทำให้กลัว แต่พูดเพราะอยากให้ครอบครัวแกมีความมั่นคงก่อนที่มันจะสายเกินไป" |
| :---- |

### **ขั้นตอนที่ 3 — ขอให้เพื่อนเป็นตัวกลาง**

| ⚠️ สิ่งที่ต้องทำก่อนขอให้เพื่อนช่วย ให้เพื่อน 'เห็นด้วย' กับสิ่งที่พูดไปก่อนเสมอ อย่าเร่งขั้นตอนนี้ ถามเพื่อนว่าเขา 'โอเค' กับสิ่งที่นิกทำไหม ก่อนขอให้ช่วยแนะนำพ่อแม่ ให้เพื่อนรู้สึกว่าเขาเป็น 'คนที่ช่วยดูแลครอบครัวตัวเอง' ไม่ใช่แค่ช่วยนิกขาย |
| :---- |

| 🤝 บทขอให้เพื่อนช่วยนัดหมายผู้ปกครอง นิก: "นิกอยากขอความช่วยเหลือจากแกจริงๆ นะ แต่ขอถามก่อนว่าแกรู้สึกยังไงกับเรื่องที่เราคุยกันบ้างมั้ย?" — หยุดรอ — ให้เพื่อนแสดงความเห็นก่อน — เพื่อน: "ก็รู้สึกว่าสำคัญนะ / คิดว่ามีประโยชน์" นิก: "ดีเลย ถ้าแกเห็นว่ามันมีประโยชน์ นิกอยากขอแค่หนึ่งอย่างเลย คือแกช่วยแนะนำนิกให้รู้จักกับพ่อหรือแม่แกได้มั้ย? แบบว่าช่วยบอกแกก่อนสั้นๆ ว่านิกจะไปทำอะไร เพื่อให้แกรู้สึกว่าเป็นการตัดสินใจของแกเอง ไม่ใช่ถูกบังคับ" — หยุดรอ — ห้ามพูดแทรก — เพื่อน: "ได้ แต่ไม่รู้ว่าพ่อแม่จะว่างไหม / โอเค ลองดู" นิก: "ขอบคุณมากเลยนะ แกแค่บอกว่า 'มีเพื่อนอยากมาแนะนำตัวและช่วยเช็กสวัสดิการให้ครอบครัว ไม่มีข้อผูกมัดอะไร' แค่นั้นเองครับ นิกทำส่วนที่เหลือเองได้เลย" — หยุด 1 วิ — นิก: "แล้วพ่อแม่แกสะดวกช่วงไหนมากกว่ากันครับ วันธรรมดาช่วงเย็น หรือวันหยุดช่วงเช้า?" — รอให้เพื่อนตอบ แล้วล็อควันทันที — |
| :---- |

### **ขั้นตอนที่ 4 — เตรียมเพื่อนก่อนวันนัด**

| 📋 สิ่งที่ต้องบอกเพื่อนก่อนวันนัด นิก: "\[ชื่อเพื่อน\] ก่อนวันที่นิกจะไปเจอพ่อแม่แก ขอฝากบอกแกก่อนสั้นๆ นะ" 1\. บอกพ่อแม่ว่า: 'เพื่อนจะมาช่วยตรวจสอบสวัสดิการที่มีอยู่ เพื่อให้รู้ว่าครอบคลุมแค่ไหน' 2\. ไม่ต้องพูดว่า 'มาขาย' เพราะงานจริงๆ ของนิกคือมาสรุปข้อมูลให้ก่อน 3\. ถ้าพ่อแม่แกถามว่าต้องซื้ออะไรไหม ให้บอกว่า 'แค่ฟังข้อมูลก่อน ไม่มีข้อผูกมัด' 4\. วันนั้นถ้าแกอยู่ด้วยได้จะดีมาก เพราะแกจะเป็นคนที่แก่แม่แกไว้ใจมากที่สุด — หยุด 1 วิ — นิก: "ขอบคุณมากนะ แกช่วยครอบครัวตัวเองได้เยอะมากเลยในวันนี้ครับ" |
| :---- |

### **กรณีพิเศษ — เพื่อนลังเล / กลัวพ่อแม่ไม่ยินดี**

| 🔄 Objection จากเพื่อน: 'กลัวพ่อแม่ไม่โอเค / ไม่กล้าบอก' เพื่อน: "กลัวพ่อแม่จะคิดว่านิกพาคนมาขายของ" นิก: "เข้าใจเลย แต่ลองคิดดูนะ ถ้าแกรู้ว่ามีอะไรที่ช่วยป้องกันครอบครัวได้ แล้วแกไม่บอก วันที่มันเกิดขึ้นจริง แกจะรู้สึกยังไง?" — หยุด 2 วิ — นิก: "แกไม่ต้องขาย แกแค่บอกพ่อแม่ว่า 'เพื่อนอยากมาช่วยเช็กให้' แค่นั้น ส่วนที่เหลือนิกทำเองได้ เพื่อนบอกพ่อแม่ว่าไว้ใจนิกได้ก็พอ" |
| :---- |

| 🔄 Objection จากเพื่อน: 'พ่อแม่มีประกันแล้ว' เพื่อน: "พ่อแม่มีประกันอยู่แล้วนะ" นิก: "ดีมากเลย แต่รู้มั้ยว่าคนส่วนใหญ่ที่มีประกันอยู่แล้วมักไม่รู้ว่ามันครอบคลุมอะไรบ้าง พอถึงเวลาใช้จริงถึงรู้ว่าไม่พอ นิกแค่อยากไปช่วยสรุปให้เห็นภาพชัดขึ้น ไม่ได้ไปเพิ่มภาระ" |

| ----- | ----- | ----- |
| Law of Egocentricity | วันนี้ลูกค้าคือ 'พระเอก' เราคือ 'กระจกเงา' | ฟังมากกว่าพูด ถามมากกว่าอธิบาย สะท้อนสิ่งที่เขาพูดกลับไปให้เขาได้ยิน |
| Law of Emotional Transfer | ส่งพลังงานบวกผ่านแววตา | ยิ้มจริง ตั้งตรง Maintain Eye Contact ไม่เบี่ยงสายตาเวลาเขาถาม |
| Law of Reciprocity | เตรียมความถ่อมตัวในฐานะคนรุ่นใหม่ | 'ผมอยากรู้มุมมองพี่เรื่องนี้ครับ' — ทำให้เขารู้สึกว่าความเห็นเขามีคุณค่า |

## **4.1 Framing — สร้าง Authority ตั้งแต่นาทีแรก**

| องค์ประกอบ | รายละเอียด | เหตุผล |
| ----- | ----- | ----- |
| การแต่งตัว | เสื้อเชิ้ตขาวเรียบกริบ กางเกงสแล็คที่ดูดี | ความเนี้ยบบอกว่าใส่ใจรายละเอียด |
| อุปกรณ์บนโต๊ะ | วาง iPad \+ ปากกาคุณภาพดี — ห้ามวางรวมกับโทรศัพท์ | แสดงว่าพร้อมทำงาน มืออาชีพ |
| ตำแหน่งนั่ง | นั่งมุม 90 องศา หรือข้างกัน — ไม่นั่งเผชิญหน้า | โฟกัสที่ข้อมูล ไม่ใช่สอบสวน |
| สถานที่ | Foyer โรงแรม หรือมุมสงบในร้านกาแฟ | สถานที่ดูแพง \= เพิ่ม Authority ให้เรา |

| 💬  First Dialogue — ประโยคเปิดเมื่อนั่งลงแล้ว นิก: "สวัสดีครับพี่ \[ชื่อ\] ขอบคุณมากนะครับที่สละเวลามาเจอกัน" *— จับมือ — ยิ้ม — นั่งลง — วางของบนโต๊ะก่อนพูดต่อ —* นิก: "วันนี้นิกตั้งใจเตรียมข้อมูลมาแชร์ให้พี่ฟังครับ เพราะนิกอยากช่วยพี่เช็กดูว่า สวัสดิการหรือแผนที่พี่มีอยู่ตอนนี้ มันยังทำงานได้คุ้มค่ากับเงินที่พี่จ่ายไปไหม" *— หยุด 1 วิ —* นิก: "ถ้าตรงไหนดีอยู่แล้ว นิกจะคอนเฟิร์มให้พี่อุ่นใจ แต่ถ้าตรงไหนมีจุดที่พี่ประหยัดได้มากกว่าเดิม นิกจะสรุปให้พี่เห็นภาพชัดๆ ไปเลยในวันนี้ครับ" |

## 

**4.2 Rapport — บทสร้างความสัมพันธ์ตาม Setting**

| 💡  เทคนิค Rapport ที่ดีไม่ใช่การถามเยอะ แต่คือการ 'ฟังจริงๆ' แล้วต่อยอดในสิ่งที่เขาพูด |
| :---- |

**🏠  Rapport — บ้านลูกค้า**

| นิก: (มองรอบๆ บ้าน) "บ้านพี่โปร่งมากเลยครับ ลมเย็นดีจัง พี่ตั้งใจแต่งสไตล์มินิมอลเลยใช่ไหมครับ?" *— หยุดฟัง — พยักหน้า ยิ้ม —* นิก: "(ชี้รูปลูก) ขออนุญาตทักนะครับ รูปน้องน่ารักมาก ตอนนี้กี่ขวบแล้วครับ?" *— ถ้ายังไม่มีลูก ให้ข้ามไปถาม Lifestyle แทน —* นิก: "วัยกำลังซนเลยนะครับ เจอหน้าน้องตอนเลิกงานคงหายเหนื่อยเป็นปลิดทิ้งเลยครับ" *— หยุดฟัง — แล้ว Transition ไป Ask Permission —* |
| :---- |

**🏢  Rapport — ออฟฟิศ / ธุรกิจ**

| นิก: "สวัสดีครับพี่ ทีมงานที่นี่ดูแอคทีฟมากเลย บรรยากาศคึกคักจัง" *— หยุด — ให้เขาพูดก่อน —* นิก: "พี่สร้างวัฒนธรรมองค์กรยังไงครับ ให้ทีมดูทำงานด้วยความสุขขนาดนี้?" *— ฟังอย่างตั้งใจ — จดโน้ตถ้ามีข้อมูลสำคัญ —* นิก: "(ดูรางวัลหรือของตกแต่ง) รางวัลพวกนี้สุดยอดมากเลยครับ กว่าจะมาถึงจุดนี้ พี่ผ่านความท้าทายอะไรมาบ้างครับ?" *— ฟังเรื่องราว — นี่คือข้อมูลสำคัญสำหรับ Insight ทีหลัง —* |
| :---- |

**☕  Rapport — ร้านกาแฟ / ที่สาธารณะ**

| นิก: "ขอบคุณที่นัดเจอร้านนี้ครับ Vibe ดี กาแฟหอมมาก พี่เลือกสรรร้านเก่งจัง" *— หยุดฟัง —* นิก: "พี่ชอบร้านบรรยากาศเงียบสงบ หรือชอบแบบคึกคักมากกว่าครับ?" *— ฟัง — แล้วต่อด้วยเรื่อง Time Management หรือ Hobby —* นิก: "ย่านนี้รถติดน่าดูเลยครับ พี่บริหารเวลาเก่งมากแน่ๆ มีเทคนิคจัดการเวลาไหมครับ?" *— ฟัง 2-3 ประโยค แล้ว Transition —* |
| :---- |

**4.3 Ask Permission — ขออนุญาตก่อนเริ่ม**

| 🙏  Ask Permission Script นิก: "เพื่อให้การคุยวันนี้คุ้มค่าเวลาพี่ที่สุด พี่สะดวกให้นิกชวนคุยตามลำดับข้อมูลที่เตรียมมา หรือมีจุดไหนที่พี่อยากให้นิกเน้นเป็นพิเศษก่อนไหมครับ?" *— หยุดรอ —* |
| :---- |

**↳  กรณี A: พี่บอกว่า 'ไม่มีจุดเน้น — เริ่มได้เลย'**

| นิก: "ได้ครับ งั้นเพื่อให้เห็นภาพรวมและจุดที่อาจยังขาดอยู่ นิกขออนุญาตสอบถามพี่ 2-3 ข้อ เพื่อให้นิกเห็นมุมมองของพี่ก่อนนะครับ" |
| :---- |

**↳  กรณี B: พี่ระบุจุดเน้น เช่น 'อยากรู้เรื่องค่าห้อง'**

| นิก: "เข้าใจเลยครับ เรื่อง \[ค่าห้อง/ภาษี\] สำคัญมาก เดี๋ยวนิกจะลงรายละเอียดส่วนนี้ให้เป็นพิเศษตอนนำเสนอนะครับ งั้นนิกขอข้อมูลปัจจุบันของพี่สัก 2-3 ข้อก่อน เพื่อให้นิกประเมินแผนได้แม่นยำที่สุดครับ" |
| :---- |

**4.4 Canvas 3P — บทถาม Present / Prize / Problem**

**1️⃣  Present — เข้าใจปัจจุบัน**

| 📊  Habits & Confidence Questions นิก: "ปกติพี่เน้นเก็บเงินในรูปแบบไหนครับ? ระหว่างฝากธนาคาร หรือแบ่งไปลงทุนในหุ้น กองทุนบ้างครับ?" *— ฟัง — จดโน้ต —* นิก: "สวัสดิการรักษาพยาบาลปัจจุบัน พี่มีตัวไหนดูแลอยู่บ้างครับ? ประกันกลุ่มบริษัท หรือประกันส่วนตัวที่เคยซื้อไว้?" *— ฟัง — จดโน้ต —* นิก: "ถ้าวันนี้ต้องใช้เงินก้อนใหญ่กะทันหัน พี่ให้คะแนนความมั่นใจกี่เปอร์เซ็นต์ครับ ว่าสวัสดิการและเงินเก็บที่มีอยู่ตอนนี้ 'เอาอยู่' แน่นอน?" *— หยุดรอ — ตัวเลขที่เขาบอกคือ Pain Point ที่จะใช้ทีหลัง —* นิก: "มีส่วนไหนในแผนการเงินปัจจุบัน ที่พี่รู้สึกว่ายังไม่ชัวร์ร้อยเปอร์เซ็นต์ไหมครับ?" *— ฟัง — นี่คือ Core Anxiety ที่จะใช้ใน Insight —* |
| :---- |

| ✅  สรุป สรุปภาพปัจจุบัน — Summarize Present นิก: "สรุปภาพปัจจุบันของพี่นะครับ... พี่เน้น \[ฝากธนาคาร/ลงทุน\] และมีสวัสดิการของ \[บริษัท/เดิม\] อยู่แล้ว โดยให้ความสำคัญกับเรื่อง \[Growth/Security\] เป็นหลัก" *— หยุด 1 วิ —* นิก: "แต่พี่ให้คะแนนความมั่นใจไว้ที่ \[X\]% เพราะยังไม่ชัวร์เรื่อง \[รายละเอียดแผน/เป้าหมาย\] ผมเข้าใจถูกต้องไหมครับ?" *— รอให้เขายืนยัน — ถ้าเขาแก้ไข ให้รับและปรับทันที —* |
| :---- |

**2️⃣  Prize — เข้าใจเป้าหมาย**

| 🌟  Vision Questions นิก: "งั้นนิกขอข้ามมาถามถึง 'เป้าหมาย' ที่พี่อยากเห็นกันบ้างครับ" *— หยุด 1 วิ —* นิก: "ถ้าทุกอย่างเป็นไปตามที่พี่หวัง 100% ในอีก 5-10 ปีข้างหน้า ภาพชีวิตที่สมบูรณ์แบบที่สุดของพี่เป็นยังไงครับ?" *— ฟัง — ห้ามรีบ ให้เขาเล่าให้จบ —* นิก: "(ต่อยอด) ในภาพนั้น พี่อยากเห็นครอบครัวมีไลฟ์สไตล์แบบไหนครับ? และถ้าภาพนั้นเกิดขึ้นจริง จุดไหนที่ทำให้พี่ภูมิใจหรือ 'หายเหนื่อย' ที่สุดครับ?" *— ฟัง — จด Keyword ที่เขาพูด เช่น 'ลูก' 'อิสระ' 'บ้าน' — จะใช้ทีหลัง —* |
| :---- |

| ✅  สรุป สรุป Prize นิก: "ฟังจากที่พี่เล่า... เป้าหมายที่พี่ต้องการที่สุด คือ \[สรุปภาพ\] เพื่อให้พี่รู้สึก \[สรุปอารมณ์\] ผมเข้าใจถูกต้องไหมครับ?" *— รอให้เขายืนยัน —* |
| :---- |

**3️⃣  Problem — เปิดเผยอุปสรรค**

| 🚧  Problem Questions นิก: "ฟังแล้วเป็นภาพที่ยอดเยี่ยมมากครับพี่... แต่เพื่อให้แผนนี้มันเกิดขึ้นได้จริงๆ นิกอยากลองชวนพี่เช็กในมุมปฏิบัติจริงครับ" *— หยุด 1 วิ —* นิก: "ตั้งแต่เริ่มวางแผนมาจนถึงตอนนี้ พี่คิดว่าเข้าใกล้เป้าหมาย \[the Prize\] ที่วางไว้กี่เปอร์เซ็นต์แล้วครับ?" *— หยุดรอ —* นิก: "อะไรคือสาเหตุหลักที่ทำให้ยังไปไม่ถึงเป้าหมาย 100% ตามที่พี่ตั้งใจไว้ครับ?" *— ฟัง — นี่คือ Barrier ที่จะใช้ใน Insight —* นิก: "ในมุมมองของพี่ อะไรคืออุปสรรคที่กังวลที่สุดที่จะขวางทางไปสู่เป้าหมายนั้นครับ? เช่น ค่าใช้จ่ายที่อาจโผล่มาในอนาคต สภาวะเศรษฐกิจที่คุมไม่ได้ หรือเรื่องสุขภาพครับ?" *— ฟัง — รอให้เขาพูด อย่าช่วยตอบแทน —* นิก: "ถ้าวันนี้เราจะปิดรอยรั่วตรงนี้ มีเงื่อนไขอะไรที่พี่ให้ความสำคัญที่สุดในการเลือกแผนครับ?" *— จด Criteria นี้ไว้ — จะใช้ใน Solution —* |
| :---- |

| ✅  สรุป สรุปทั้ง 3P นิก: "นิกสรุปภาพรวมของพี่นะครับ... ปัจจุบันพี่จัดการเงินไว้ที่ \[Present\] เพื่อไปให้ถึงเป้าหมาย \[Prize\] แต่พี่มีความกังวลเรื่อง \[Problem\] และให้ความสำคัญกับเงื่อนไข \[Criteria\] เป็นอันดับแรก" *— หยุด 1 วิ —* นิก: "ผมเข้าใจภาพรวมของพี่ถูกต้องไหมครับ?" *— รอยืนยัน — ถ้าเขาแก้ ให้รับทันทีโดยไม่เถียง —* |
| :---- |

**4.5 Insights — บทเล่าเรื่องตาม Persona (6 แบบ)**

| 💡  เทคนิค เลือก Insight ให้ตรงกับ Persona ที่สรุปได้จากการถาม 3P — ใช้เวลา 90 วินาที ไม่เกิน 3 นาที |
| :---- |

| INSIGHT \#1 — 💼 นักลงทุน / HNW นิก: "ขอบคุณครับพี่ จากที่พี่กังวลเรื่อง \[Problem ที่เขาบอก\] นิกขออนุญาตแชร์เรื่องหนึ่งที่นิกเจอมาจากการดูแลพี่ๆ นักลงทุนครับ" *— หยุด 1 วิ —* นิก: "นักลงทุนส่วนใหญ่คงไม่มีใครทิ้งเงินสดไว้เฉยๆ ให้เสียโอกาสถูกต้องไหมครับ ทุกบาทต้องไปทำงานในสินทรัพย์ที่งอกเงยอยู่แล้ว" *— พยักหน้ายืนยัน — รอให้เขาพยักหน้าตาม —* นิก: "แต่จุดที่น่ากังวลที่สุดคือ 'จังหวะการใช้เงิน' ครับ ถ้ามีเหตุฉุกเฉินให้ต้องใช้เงินสดหลักล้านกะทันหัน ในวันที่ตลาดหุ้นผันผวน หรืออสังหาฯ ที่ยังเปลี่ยนเป็นเงินสดไม่ได้... เราจะตกอยู่ในสถานะที่ 'เสียเปรียบตลาด' ทันทีครับ" นิก: "เพราะพี่ถูกบังคับให้ต้องขายของในราคาขาดทุน เพียงเพื่อเอาเงินมาแก้ปัญหาเฉพาะหน้า มันคือการทำลายผลตอบแทนที่ลงทุนมาทั้งชีวิตให้พังลงในวันเดียว เพียงเพราะขาดสภาพคล่องเงินสดครับ" *— หยุด 3 วิ — ให้ภาพนั้นนั่งอยู่ในหัวเขา —* |
| :---- |

| INSIGHT \#2 — 🏢 เจ้าของธุรกิจ นิก: "ในฐานะเจ้าของธุรกิจ พี่สร้างระบบให้ลูกน้องทำงานแทนได้ดีเลยครับ แต่สิ่งที่นักธุรกิจส่วนใหญ่มักเจอคือ 'ตัวพี่คือฟันเฟืองหลัก' ของระบบการเงินทั้งหมดเสมอ" *— หยุด 1 วิ —* นิก: "ในการทำบัญชี พี่อาจกันเงินสำรองไว้เป็นทุนหมุนเวียนดีแล้ว แต่สิ่งที่มักถูกมองข้ามคือ 'ความต่อเนื่องของรายได้' ในวันที่ฟันเฟืองหลักอย่างพี่ต้องหยุดทำงานกะทันหันครับ" นิก: "เพราะเมื่อรายได้จากธุรกิจสะดุด แต่ค่าใช้จ่ายคงที่ทั้งในบริษัทและในบ้านยังไม่หายไปไหน สุดท้ายเราจะถูกบังคับให้ดึงเงินหมุนเวียนจากธุรกิจออกมาจ่ายค่าบ้าน ค่ากินอยู่ และค่าเทอมลูกแทนครับ" *— หยุด 2 วิ —* นิก: "กลายเป็นจุดเปลี่ยนที่ทำให้ธุรกิจที่สร้างมาต้องถอยหลังกลับไปเริ่มใหม่ เพียงเพราะระบบการเงินส่วนตัวกับบริษัทมันแยกกันไม่ออกครับ" *— หยุด 3 วิ —* |
| :---- |

| INSIGHT \#3 — 👔 พนักงานประจำ นิก: "สวัสดิการบริษัทที่พี่มีอยู่ตอนนี้ยอดเยี่ยมครับ แต่มุมที่คนทำงานระดับมืออาชีพมักมองข้ามคือ มันเป็น 'สวัสดิการติดโต๊ะ' ครับ" *— หยุด 1 วิ —* นิก: "ตราบใดที่พี่นั่งทำงานที่นี่ พี่อุ่นใจได้ร้อยเปอร์เซ็นต์ครับ แต่ความจริงคือ บริษัทออกแบบสวัสดิการมาเพื่อให้พี่หายดีแล้วกลับมาทำงานให้เขาได้เร็วที่สุดครับ" นิก: "ถ้าวิกฤตครั้งนั้นหนักจนพี่ต้องหยุดงานนานเกินไป ยังไงเขาก็ต้องหาคนอื่นมาแทนที่เรา" *— หยุด 2 วิ —* นิก: "ทันทีที่พี่ลุกจากโต๊ะนั้นไป รายได้และสวัสดิการจะหายไปทันที ในขณะที่ค่าใช้จ่ายในชีวิตยังไม่หายไปไหน และที่สำคัญคือถ้าเรารอจนถึงวันนั้นเพื่อจะสร้าง 'สวัสดิการติดตัว' ให้ตัวเอง ก็อาจทำไม่ได้แล้วเพราะไม่มีที่ไหนรับครับ" *— หยุด 3 วิ —* |

| INSIGHT \#4 — 💻 Freelance / นายตัวเอง นิก: "แผนเกษียณหรือเป้าหมายหลักสิบล้านที่พี่ตั้งเป้าไว้ 20 ปี จริงๆ มันตั้งอยู่บนเงื่อนไขที่อันตรายมากข้อหนึ่งครับ" *— หยุด 1 วิ — ให้เขาสงสัย —* นิก: "คือพี่ต้องภาวนาให้โลกนี้ใจดีกับพี่ตลอด 20 ปีนั้น" *— หยุด 2 วิ —* นิก: "ไม่ว่าจะเป็นวิกฤตเศรษฐกิจที่ทำให้การลงทุนสะดุด หรือวิกฤตสุขภาพที่มาแบบไม่ทันตั้งตัว ปัจจัยภายนอกพวกนี้คือตัว 'หยุดเวลา' ของเราครับ" นิก: "ถ้าพรุ่งนี้เวลาหาเงินของเราถูกตัดจบลงกะทันหัน แผนที่วางไว้ 20 ปีจะเหลือเพียงเศษเสี้ยวของเงินออมที่ทำมาได้แค่ไม่กี่ปี ซึ่งมันไม่มีทางพอสำหรับอนาคตที่พี่หวังไว้แต่แรกครับ" *— หยุด 3 วิ —* นิก: "พี่กำลังฝากชีวิตไว้กับ 'ดวง' ว่าจะอนุญาตให้เรามีเวลาทำงานจนครบกำหนดหรือเปล่า และนั่นเป็นเรื่องที่เราควบคุมไม่ได้เลยครับ" |

| INSIGHT \#5 — 👨‍👩‍👧 หัวหน้าครอบครัว นิก: "พี่วางแผนเก็บเงินและลงทุนเพื่ออนาคตของน้องและครอบครัวมาอย่างดีมากเลยครับ ซึ่งถือเป็นความรับผิดชอบที่ยิ่งใหญ่มากครับ" *— หยุด 1 วิ —* นิก: "แต่ในทางวางแผนการเงิน แผนนี้มีเงื่อนไขที่อันตรายที่สุดข้อหนึ่ง คือพี่ต้องภาวนาให้โลกนี้ 'ใจดี' กับพี่ตลอด 20 ปีที่น้องยังเรียนไม่จบครับ" นิก: "ถ้าพรุ่งนี้เวลาหาเงินของพี่ถูกตัดจบลงกะทันหัน แผนที่พี่ตั้งเป้าว่าจะส่งน้องเรียนจนจบ หรือมีมรดกให้ครอบครัว จะเหลือเพียงมูลค่าเงินออมที่ทำมาได้แค่ไม่กี่ปี ซึ่งมันไม่เคยพอสำหรับชีวิตของคนที่เหลืออยู่เลยครับ" *— หยุด 3 วิ — สำคัญมาก ห้ามพูดแทรก —* นิก: "พี่กำลังฝากอนาคตของคนที่พี่รักที่สุดไว้กับ 'โชคชะตา' ว่าจะอนุญาตให้พี่มีเวลาดูแลเขาจนครบกำหนดหรือเปล่า ซึ่งนั่นเป็นเรื่องที่พี่คุมไม่ได้เลยครับ" |

**4.6 Methodology — วิธีการแก้ปัญหาตาม Persona**

| 💡  Internet Metaphor — ใช้กับทุก Persona นิก: "เปรียบเทียบง่ายๆ เหมือนวันนี้พี่ต้องใช้เน็ตเพื่อทำงาน พี่คงไม่รอเก็บเงินสดหลักล้านเพื่อไป 'สร้างเสาสัญญาณเอง' ในบ้านใช่ไหมครับ?" *— รอให้เขาพยักหน้า —* นิก: "แต่สิ่งที่พี่เลือกทำคือการ 'จ่ายค่าเน็ตรายเดือน' แค่หลักร้อยหรือหลักพัน เพื่อให้พี่ 'เข้าถึงโครงข่ายมูลค่าหมื่นล้าน' ตั้งแต่วันแรกครับ" *— หยุด 1 วิ —* นิก: "วิธีที่นิกแนะนำก็เหมือนกันครับ คือการใช้เงินที่เราซื้อข้าว ซื้อกาแฟ 'เช่าเงินสดสำรอง' เตรียมไว้ให้พร้อม ตั้งแต่วันนี้เลย โดยไม่ต้องเสียเวลาไปนั่งสร้างกองเงินสดด้วยตัวเองครับ" |
| :---- |

| 💼  Methodology — นักลงทุน นิก: "พี่ครับ ปกติถ้านิกเอาเงินให้พี่ 1 ล้าน พี่มั่นใจว่าทำกำไรให้งอกเงยได้ปีละกี่เปอร์เซ็นต์ครับ?" *— รอเขาตอบ —* นิก: "ยอดเยี่ยมครับพี่ ยิ่งกำไรเยอะยิ่งรวยเร็ว แต่ถ้านิกบอกว่าขอตัด 'เศษกำไร' แค่ 2-3% จากพอร์ตนั้น ออกมาสร้าง 'โครงข่ายเงินสดสำรอง' ไว้ พี่คิดว่ากำไรที่หายไปแค่นิดเดียวนี้จะกระทบกับชีวิตหรือพอร์ตไหมครับ?" *— รอ — ส่วนใหญ่จะบอกว่าไม่กระทบ —* นิก: "นั่นแหละครับคือ Key สำคัญ เงิน 3% นี้จะ Lock สิทธิ์เงินล้านไว้ให้พี่ทันที วันไหนที่วิกฤตสุขภาพมา พี่จะมีเงินสดพร้อมจ่าย โดยไม่ต้องไปถอนพอร์ตที่กำลังทำกำไรอยู่ครับ" นิก: "พี่ว่าการตัด 2-3% ออกจากพอร์ต เพื่อให้มั่นใจว่าพอร์ตหลักจะไม่ถูกบังคับขายตอนวิกฤต แบบนี้ Make Sense กับวิธีที่พี่บริหารเงินอยู่ตอนนี้ไหมครับ?" |
| :---- |

| 🏢  Methodology — เจ้าของธุรกิจ นิก: "สำหรับเจ้าของธุรกิจอย่างพี่ วิธีการคือการ 'จ้างพนักงานพิเศษ' เพิ่มอีกสักคนในค่าจ้างที่ถูกมากครับ" *— หยุด 1 วิ — ให้เขาสงสัย —* นิก: "พนักงานคนนี้อาจดูเหมือนเป็นภาระที่พี่ต้องจ่ายเงินเดือนให้ทุกปีโดยที่เขายังไม่ได้เริ่มทำงานอะไร แต่ข้อดีคือเขาเป็นพนักงานที่กตัญญูที่สุดครับ เพราะวันไหนที่พี่เกิดวิกฤตจนทำงานต่อไม่ไหว พนักงานคนนี้จะก้าวออกมาทำหน้าที่แทนพี่ทั้งหมดทันที" นิก: "พี่ว่าการมีพนักงานคนนี้คอยรันแทนในวันที่พี่หยุดไม่ได้ แบบนี้ตอบโจทย์ธุรกิจพี่ไหมครับ?" |
| :---- |

| 👔  Methodology — พนักงานประจำ นิก: "สำหรับคนทำงานที่มองการณ์ไกล วิธีการคือการสร้าง 'กระเป๋าสวัสดิการส่วนตัว' ที่ติดตัวพี่ไปทุกที่ครับ" นิก: "เพราะความจริงคือสวัสดิการบริษัทมันคือการยืมจมูกคนอื่นหายใจ วันไหนที่พี่ย้ายงาน เกษียณ หรือบริษัทเปลี่ยนนโยบาย สิทธิ์เหล่านั้นก็หายไปทันที" นิก: "แต่ระบบที่นิกแนะนำ จะทำหน้าที่ดูแลพี่ร้อยเปอร์เซ็นต์เสมอไม่ว่าพี่จะอยู่ที่ไหน พี่จะเป็นเจ้าของสวัสดิการที่ใหญ่กว่าเดิมในราคาที่พี่คุมเองได้ครับ" นิก: "พี่ว่าการมีกระเป๋าสวัสดิการที่ติดตัวไปทุกที่ ไม่ขึ้นกับโต๊ะทำงานใคร แบบนี้ตอบโจทย์พี่ไหมครับ?" |
| :---- |

| 💻  Methodology — Freelance / นายตัวเอง นิก: "สำหรับนายตัวเอง วิธีการคือการ 'ล็อคสิทธิ์ตัวแทน' ให้กับตัวเองก่อนเลยครับ" นิก: "เหมือนกับที่พี่สร้างรายได้ด้วยตัวเอง เราก็ต้องสร้างหลักประกันด้วยตัวเองในแบบเดียวกัน ระบบที่นิกแนะนำจะทำงานเป็น 'Safety Net' ที่พี่ตั้งขึ้นเอง และมันจะคอยรองรับพี่ตลอดเวลาครับ" นิก: "พี่ว่าการมี Safety Net แบบนี้ที่ไม่ต้องรอให้ใครมาดูแล ตอบโจทย์ความเป็นนายตัวเองของพี่ไหมครับ?" |
| :---- |

| 👨‍👩‍👧  Methodology — หัวหน้าครอบครัว นิก: "สำหรับพี่ที่เป็นเสาหลักของบ้าน วิธีการคือการ 'ซื้อความสำเร็จล่วงหน้า' ครับ โดยเราจะเน้นไปที่การล็อคเงินสดมูลค่าเท่ากับ 'รายได้ของพี่อย่างน้อย 5 ปี' มาไว้ในมือตั้งแต่วันนี้เลยครับ" นิก: "เหตุผลคือถ้าเกิดอะไรขึ้นกะทันหัน ครอบครัวพี่จะมีเวลาตั้งตัวถึง 5 ปีโดยที่ไม่ต้องเปลี่ยนรูปแบบการใช้ชีวิตแม้แต่นิดเดียว" นิก: "นี่คือการการันตีความรักที่จับต้องได้จริงที่สุดครับ" *— หยุด 2 วิ —* นิก: "พี่ว่าการล็อคเงิน 5 ปีไว้ให้ครอบครัวตั้งแต่วันนี้ โดยไม่ต้องรอเก็บเองอีก 20 ปี แบบนี้ตอบโจทย์สิ่งที่พี่อยากให้ครอบครัวได้รับไหมครับ?" |

| 🎯  Ball Boy Technique — ถ้าเขาติดอยู่กับ Objection ใดๆ นิก: "เข้าใจเลยครับพี่ เรื่อง \[ราคา/เวลา/ขอคิดก่อน\] เป็นประเด็นสำคัญ นิกขออนุญาตจดไว้ก่อนนะครับ..." *— จดลงในโน้ตจริงๆ ให้เขาเห็น — แสดงว่าคุณฟังและให้ความสำคัญ —* นิก: "นอกจากจุดนี้แล้ว มีตรงไหนในแผนที่พี่อยากให้นิกปรับจูนเพื่อให้มัน 'พอดี' กับพี่มากกว่านี้ไหมครับ?" *— รอฟัง — เก็บ Objection ทั้งหมดก่อนตอบ —* |
| :---- |

**4.8 Closing Objections — 8 ข้อโต้แย้งเมื่อจะปิดการขาย**

| 💡  เทคนิค ระบบ Agree → Trigger → Metaphor → Close ทุกครั้ง |
| :---- |

| 🔄  OBJ 1: 'ขอกลับไปคิดดูก่อน' |
| :---- |
| **Agree:** จริงพี่ ผมเห็นด้วยเลย พี่ควรใช้เวลาคิดให้ชัวร์ครับ เพราะนี่คือเงินพี่และความมั่นคงของที่บ้านเนาะ **Trigger:** แต่พี่... ระหว่างที่พี่กลับไปนอนคิดเนี่ย ไอ้ความเสี่ยงมันไม่ได้หยุดพักร้อนไปกับพี่ด้วยนะพี่ พี่แอบกังวลป่ะถ้าแจ็กพอตมันดันทลายลงมาระหว่างที่เรากำลังตัดสินใจ? **Metaphor:** เอาเงี้ยพี่... ให้บริษัทผม 'ช่วยคิด' ไปพร้อมกับพี่เลยดีกว่า คือวันนี้เราเซ็นจองสิทธิ์ Lock ความคุ้มครองไว้ก่อน พอเล่มกรมธรรม์ถึงมือพี่ พี่มีเวลาทบทวนฟรีๆ อีก 15 วัน (Free Look) ถ้าอ่านแล้วไม่ใช่ พี่คืนเล่มได้เงินคืนครบทุกบาทครับ **Close: ไปนอนคิดแบบที่มีความคุ้มครองกอดอุ่นๆ ดีกว่านอนคิดตัวเปล่าแบบเสียวๆ เนาะพี่... เซ็นจองสิทธิ์ไว้ก่อนเลยครับ** |

| ⏰  OBJ 2: 'ยุ่งมาก / ไว้ก่อน / ค่อยว่ากันใหม่' |
| :---- |
| **Agree:** เข้าใจเลยพี่ ทุกคนยุ่งหมดครับ และเพราะพี่ยุ่งนี่แหละผมถึงต้องรีบคุย **Trigger:** แต่พี่ครับ... บัตรประชาชนบอกวันเกิดเรานะพี่ แต่ไม่มีบัตรใบไหนบอกวันตายว่ะพี่ เราจะไปบอกยมบาลได้ไหมว่า 'ตอนนี้ยุ่งอยู่ ยังไม่พร้อมไป'? **Metaphor:** วันที่ทำประกันดีที่สุดคือ 'วันก่อนเกิดเหตุ 1 วัน' ครับ แต่เราไม่รู้ไงว่าวันนั้นคือวันไหน ทำเร็วไป 1 ปี ดีกว่าทำช้าไป 1 วันนะพี่ **Close: ผมขอเอาความกังวลนี้กลับไปดูแลแทนพี่เองครับ รบกวนเซ็นตรงนี้เลยพี่** |

| 📉  OBJ 3: 'ทำประกันแล้วขาดทุน / ไม่คุ้ม' |
| :---- |
| **Agree:** เข้าใจเลยพี่ พี่เป็นนักลงทุนก็ต้องมองผลตอบแทนเป็นหลักอยู่แล้ว **Trigger:** แต่พี่ครับ... พี่ขับรถคันละล้าน จ่ายประกันปีละ 5 หมื่น ถ้าปีนั้นรถไม่ชนเลย พี่จะบ่นว่า 'ขาดทุนจังไม่ได้ชน' หรือพี่จะบอกว่า 'โชคดีจังรถไม่พัง' ว่ะพี่? **Metaphor:** ชีวิตมี 2 หน้าพี่: 'กำไรเงินตรา ขาดทุนชีวิต' (ได้เงินเคลม) กับ 'ขาดทุนเงินตรา กำไรชีวิต' (จ่ายเบี้ยทิ้งแต่ได้อยู่กอดลูกหลาน) ถ้าพี่รู้สึกขาดทุนเงินเบี้ย นั่นแปลว่าพี่กำลัง 'กำไรชีวิต' อยู่นะพี่ **Close: พี่อยากได้กำไรชีวิต แล้วยอมขาดทุนเงินเศษตังค์นิดหน่อยไหมพี่? เซ็นตรงนี้เพื่อกำไรชีวิตครับ** |

| 📈  OBJ 4: 'เอาเงินไปลงทุนหุ้นดีกว่า' |
| :---- |
| **Agree:** ผมเห็นด้วย 100% พี่ ลงทุนหุ้นหวังผล 10-20% ย่อมดีกว่าประกันแน่นอน **Trigger:** แต่พี่เคยเจอการลงทุนแบบนี้ป่ะ: 'ลงเงินแค่ 3% แต่การันตีผลตอบแทนให้ลูกพี่ 100% ทันทีตั้งแต่วันแรก'? **Metaphor:** สมมติผมขอฝากเงินกับพี่ปีละ 3 แสน แต่ถ้าผมเป็นอะไรไป พี่ต้องจ่ายให้ครอบครัวผม 10 ล้าน พี่กล้ารับป่ะ? ถ้ายอมรับไม่ได้... ทำไมพี่ไม่ให้บริษัทประกันรับความเสี่ยงที่ 'ได้เปรียบ' แบบนี้แทนพี่ล่ะครับ? **Close: รับดีล 3% แลก 100% นี้ไว้ปกป้องพอร์ตหุ้นพี่ไหม? เซ็นตรงนี้ครับ** |

| 💸  OBJ 5: 'เบี้ยแพง / ไม่มีเงิน' |
| :---- |
| **Agree:** เข้าใจพี่ เบี้ยดูเหมือนแพงและเป็นภาระเนอะ **Trigger:** แต่ถ้าพี่ไม่ทำประกัน พี่กำลังเปิด 'บริษัทประกันชีวิต' ให้ตัวเองอยู่นะพี่ ถ้าเจ็บป่วยขึ้นมา พี่ต้องเป็นคนจ่ายสินไหมให้ตัวเองทั้งหมดเลยนะ **Metaphor:** สิ่งที่แพงที่สุดไม่ใช่เบี้ยครับพี่ แต่คือการ 'ไร้หลักประกัน' ในวันที่วิกฤตมาถึง **Close: ใช้เงินก้อนเล็กปกป้องเงินก้อนใหญ่ดีกว่าพี่... เซ็นตรงนี้ครับ** |

| 🏥  OBJ 6: 'มีสวัสดิการบริษัทแล้วพอ' |
| :---- |
| **Agree:** ดีเลยพี่ บริษัทพี่สวัสดิการสุดยอดจริงๆ **Trigger:** แต่พี่ครับ... สวัสดิการบริษัทมันเหมือน 'เสื้อกันฝน' ว่ะพี่ กันฝนตกพรำๆ ได้ แต่ถ้าเจอ 'พายุไต้ฝุ่น' (มะเร็ง) พี่ว่ามันจะกันไหวป่ะ? **Metaphor:** ทันทีที่พี่ลาออกหรือเกษียณ เขาขอเสื้อกันฝนคืนนะพี่ ถึงตอนนั้นจะไปสร้างบ้านหลบภัยก็ไม่ทันแล้ว **Close: สร้างบ้านหลบภัยส่วนตัวไว้ตั้งแต่วันที่ฟ้ายังใสดีกว่าเนาะพี่เนาะ** |

| 💬  OBJ 7: 'ขอถามภรรยาก่อน' |
| :---- |
| **Agree:** ให้เกียรติแฟนเป็นเรื่องดีครับพี่ ลูกผู้ชายตัวจริงเลย **Trigger:** แต่ผมแนะนำให้พี่ลองไป 'ปรึกษาแม่ม่าย' ดูด้วยนะพี่ เธอรู้ดีที่สุดว่าการเสียเสาหลักโดยไม่มีประกันมันลำบากขนาดไหน **Metaphor:** ถ้าเดินอยู่แล้วรถเบรกแตกพุ่งมา พี่จะถามแฟนไหมว่า 'ดึงหลบไหม?' หรือพี่จะกระชากหลบเลย? การทำประกันคือการดึงแฟนหลบจากความจนว่ะพี่ **Close: คนที่เรารักไม่ต้องถามครับ ปกป้องเลยพี่... เซ็นตรงนี้ครับ** |

| 🏠  OBJ 8: 'เอาเงินไปผ่อนบ้านก่อนดีกว่า' |
| :---- |
| **Agree:** เข้าใจพี่ ผ่อนบ้านเป็นภาระใหญ่และสำคัญมาก **Trigger:** แต่ถ้าเกิดแจ็กพอตขึ้นมา ใครจะผ่อนต่อพี่? ถ้าขาดรายได้ แบงก์ยึดบ้านทันที เงินที่ผ่อนมาทั้งหมดหายวับเลยนะ **Metaphor:** พี่อยากให้บ้านหลังนี้เป็น 'ของลูก' หรือ 'ของแบงก์' ว่ะพี่? **Close: เซ็นตรงนี้เพื่อมอบบ้านปลอดหนี้ให้ลูกพี่เถอะครับ** |

**4.9 The 3-Yes Close — ปิดการขายด้วย 3 คำถาม**

| ✅  The 3-Yes Close นิก: "พี่ครับ ฟังมาถึงตรงนี้ ผมขอสรุปสั้นๆ เพื่อความเข้าใจตรงกันนะครับ... วันนี้ที่พี่สนใจฟัง เพราะพี่ต้องการวางแผนปกป้องคนที่พี่รักที่สุด ใช่ไหมครับ?" *— รอให้เขาตอบ 'ใช่' — Yes \#1 —* นิก: "แล้วพี่เห็นด้วยกับผมไหมครับว่า กรมธรรม์ฉบับนี้ไม่ใช่แค่ความคุ้มครอง แต่มันคือการออมเงินก้อนใหญ่ให้ตัวพี่เองในอนาคตด้วย?" *— รอ 'ใช่' — Yes \#2 —* นิก: "แถมรัฐบาลยังสนับสนุนให้เอาไปลดหย่อนภาษีได้อีก... เท่ากับได้ความคุ้มครอง ได้เงินออม และได้เงินคืนจากภาษี... พี่ว่าเงื่อนไขแบบนี้ ดีไหมครับ?" *— รอ 'ดี' — Yes \#3 —* นิก: "ถ้าอย่างนั้น รบกวนขอบัตรประชาชนพี่ เพื่อเริ่มความคุ้มครองให้พี่และครอบครัวเลยครับ" *— ยื่นมือรับบัตร — กระทำทันที อย่ารอ —* |
| :---- |

**3 กรณีหลัง Presentation**

| ✅  กรณี 1: ลูกค้าตกลงซื้อ นิก: "ยอดเยี่ยมครับพี่ที่เลือกความชัวร์ให้ครอบครัวตั้งแต่วันนี้ เดี๋ยวเรามาลงรายละเอียดเบื้องต้นเพื่อ 'ล็อคสิทธิ์' นี้ให้ทำงานแทนพี่ตั้งแต่วันนี้เลยนะครับ พี่สะดวกใช้บัตรเครดิตหรือโอนดีครับ?" *— รับบัตรประชาชนและเริ่ม Application ทันที —* |
| :---- |

| 🔄  กรณี 2: ขอคิดดูก่อน — ปิดเพื่อเปิดนัดถัดไป นิก: "นิกเข้าใจครับพี่ เรื่องอนาคตต้องรอบคอบเป็นธรรมดา... งั้นเพื่อให้พี่ได้ข้อมูลไปประกอบการตัดสินใจได้ครบที่สุด นิกขออนุญาต 'นัดเวลาสั้นๆ' อีกครั้งใน \[ระบุวัน/เวลา\] เพื่อมาฟังคำตอบจากพี่ หรือถ้าพี่มีคำถามเพิ่มนิกจะได้เตรียมข้อมูลมาให้พร้อมเลย พี่สะดวกเป็นช่วงเช้าหรือบ่ายดีครับ?" |
| :---- |

| 🎯  กรณี 3: Assumptive Close นิก: "แบบประกันตัวนี้ตอบโจทย์เรื่องทุนการศึกษาลูกได้ดีมากเลยครับพี่..." *— พูดเรื่อง Product ต่อแบบธรรมชาติ แล้วค่อย Pivot ลงรายละเอียด —* นิก: "พี่ครับ... ปกติสุขภาพพี่แข็งแรงดี ไม่มีประวัติเข้าโรงพยาบาลหรือมีโรคประจำตัวอะไรใช่ไหมครับ?" *— ถามสุขภาพแบบธรรมชาติ — เริ่ม Application Flow —* นิก: "ได้ครับ แล้วทุนการศึกษาก้อนนี้ พี่อยากให้ลงชื่อน้อง \[ชื่อลูก\] คนเดียวเลย หรือจะแบ่งให้พี่ \[ชื่อแฟน\] ไว้จัดการด้วยดีพี่?" นิก: "ได้ครับ งั้นรบกวนพี่เซ็นชื่อตรงนี้ เพื่อยืนยันความรักให้ลูกครับ" |
| :---- |

**4.10 Two Meeting Audit System — ระบบ 2 นัด สำหรับลูกค้าที่มีกรมธรรม์หลายฉบับ**

| 💡  เทคนิค ทำไมต้องใช้ระบบ 2 นัด? ลูกค้าที่มีกรมธรรม์หลายฉบับมักไม่รู้ว่าตัวเองมีอะไรบ้าง การขอนำกรมธรรม์ไปวิเคราะห์ก่อน แสดงความเป็นมืออาชีพและสร้าง Authority ได้ดีมาก เมื่อนำกลับมาพร้อมใบสรุปที่ชัดเจน โอกาสปิดการขายในนัดสองสูงมาก |
| :---- |

| นัด | เป้าหมาย | ผลลัพธ์ที่ต้องได้ |
| :---- | :---- | :---- |
| นัดที่ 1 | สร้างความสัมพันธ์ \+ รับกรมธรรม์ไปวิเคราะห์ | ได้กรมธรรม์ตัวจริงทุกเล่ม \+ กำหนดวันนัดสอง |
| ระหว่างนัด | วิเคราะห์กรมธรรม์และจัดทำใบสรุปสวัสดิการ | FA Policy Audit Sheet ที่สมบูรณ์ \+ ระบุรอยรั่ว |
| นัดที่ 2 | ส่งมอบใบสรุป \+ นำเสนอ Solution ปิดรอยรั่ว | ปิดการขาย หรือได้ข้อมูลเพิ่มเพื่อ Follow-up ต่อ |

**นัดที่ 1 — บทสนทนาขอรับกรมธรรม์ไปวิเคราะห์**

| 📋  บทพูดขอรับกรมธรรม์ตัวจริง — หลัง Rapport และ 3P นิก: "พี่ครับ จากที่คุยกันมา นิกอยากช่วยพี่ทำสิ่งหนึ่งที่จะมีประโยชน์มากๆ เลย" *— หยุด 1 วิ —* นิก: "นิกอยากขอรับกรมธรรม์ของพี่ทุกเล่มที่มีอยู่ไปวิเคราะห์ให้ละเอียดครับ เพื่อจัดทำ 'ใบสรุปสวัสดิการ' ให้พี่เห็นภาพรวมทั้งหมดในหน้าเดียว" *— หยุดรอให้เขาตอบสนอง —* |
| :---- |
