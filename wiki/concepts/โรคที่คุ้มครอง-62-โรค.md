# 62 โรคที่คุ้มครอง — AIA CI ProCare (6 กลุ่ม)

**แหล่งที่มา:** [[sources/aia-ci-procare-brochure]] | **บริษัท:** [[entities/AIA-เอไอเอ]]

> [!NOTE]
> ครอบคลุม 62 โรค/การรักษา แบ่งเป็น **18 โรคระยะต้น–ปานกลาง** และ **44 โรคระยะรุนแรง** ใน 6 กลุ่ม

---

## กลุ่ม 1: มะเร็งและเนื้องอก

| ระดับ | โรค/การรักษา |
|-------|------------|
| **ระยะต้น–ปานกลาง (40%)** | มะเร็งที่ยังไม่รุกราน (Non-invasive cancer) |
| | การผ่าตัดเนื้องอกต่อมใต้สมอง (Pituitary tumor surgery) |
| **ระยะรุนแรง (100%)** | มะเร็งรุกราน (Invasive cancer) |
| | เนื้องอกสมองชนิดไม่ร้ายแรง (Non-malignant brain tumor) |

---

## กลุ่ม 2: หัวใจ หลอดเลือด และระบบไหลเวียนโลหิต

| ระดับ | โรค/การรักษา |
|-------|------------|
| **ระยะต้น–ปานกลาง (40%)** | การผ่าตัดขยายหลอดเลือดหัวใจ (Angioplasty) |
| | การใส่เครื่องกระตุ้นหัวใจ (Cardiac pacemaker insertion) |
| **ระยะรุนแรง (100%)** | กล้ามเนื้อหัวใจตายเฉียบพลัน (Acute myocardial infarction) |
| | การผ่าตัดบายพาสหลอดเลือดหัวใจ (Coronary artery bypass surgery) |
| | การผ่าตัดหลอดเลือดแดงใหญ่ (Aorta surgery) |
| | โรคหัวใจระยะรุนแรงอื่นๆ |

---

## กลุ่ม 3: ระบบประสาทและกล้ามเนื้อ

| ระดับ | โรค/การรักษา |
|-------|------------|
| **ระยะต้น–ปานกลาง (40%)** | พาร์กินสันระยะเริ่มต้น (Early-stage Parkinson's) |
| | อัลไซเมอร์ระยะเริ่มต้น (Early-stage Alzheimer's) |
| | การผ่าตัดหลอดเลือดแดงคาโรติด (Carotid endarterectomy) |
| **ระยะรุนแรง (100%)** | โรคหลอดเลือดสมอง (Stroke) |
| | โคม่า (Coma) |
| | อัลไซเมอร์ระยะรุนแรง (Alzheimer's disease) |
| | พาร์กินสันระยะรุนแรง (Parkinson's disease) |
| | Multiple Sclerosis |
| | อัมพาต (Paralysis) |

---

## กลุ่ม 4: อวัยวะหลักและระบบสำคัญ

| ระดับ | โรค/การรักษา |
|-------|------------|
| **ระยะต้น–ปานกลาง (40%)** | การผ่าตัดตับ 1 พลีก (Liver surgery — one lobe) |
| | การตัดไต 1 ข้าง (Kidney removal — one kidney) |
| | การตัดปอด 1 ข้าง (Lung removal — one lung) |
| **ระยะรุนแรง (100%)** | ตับวาย (Liver failure) |
| | ไตวายเรื้อรัง (Kidney failure) |
| | การปลูกถ่ายอวัยวะสำคัญ (Major organ transplant) |
| | SLE ที่มีภาวะแทรกซ้อนที่ไต (Lupus nephritis) |

---

## กลุ่ม 5: การติดเชื้อ บาดเจ็บสำคัญ และความพิการ

| ระดับ | โรค/การรักษา |
|-------|------------|
| **ระยะต้น–ปานกลาง (40%)** | แผลไฟไหม้ระดับน้อย (Minor burns) |
| **ระยะรุนแรง (100%)** | แผลไฟไหม้รุนแรง (Major burns) |
| | การบาดเจ็บที่ศีรษะรุนแรง (Major head trauma) |
| | ทุพพลภาพถาวรสิ้นเชิง (Total and Permanent Disability — TPD) |

---

## กลุ่ม 6: โรคในเด็ก (อายุ 0–16 ปี)

| ระดับ | โรค/การรักษา |
|-------|------------|
| **ระยะต้น–ปานกลาง (40%)** | ไข้เลือดออก (Dengue hemorrhagic fever) |
| **ระยะรุนแรง (100%)** | โรคคาวาซากิที่มีภาวะแทรกซ้อนที่หัวใจ (Kawasaki disease with cardiac complications) |
| | เบาหวานชนิดที่ 1 (Type 1 Diabetes Mellitus) |
| | โรคเด็กร้ายแรงอื่นๆ |

---

## โรคที่คุ้มครองซ้ำ (Relapsed CI)

3 โรคหลักที่คุ้มครองกรณีเป็นซ้ำหรือรักษาไม่หาย:
1. **มะเร็ง** (Cancer)
2. **กล้ามเนื้อหัวใจตายเฉียบพลัน** (Acute Myocardial Infarction)
3. **โรคหลอดเลือดสมอง** (Stroke)
