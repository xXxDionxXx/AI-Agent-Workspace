## **Core Philosophy — ปรัชญาพื้นฐาน**

| หลัก | ความหมาย |
| ----- | ----- |
| Sales is the Lifeblood | การขายคือเส้นเลือดใหญ่ของธุรกิจ ถ้าไม่มีการขาย ธุรกิจก็ไม่มีออกซิเจน |
| LAPS Rhythm | ความสำเร็จไม่ได้เกิดจากโชค แต่เกิดจาก 'จังหวะ' ที่สม่ำเสมอในทุกสัปดาห์ |
| Value-Driven | เราไม่ได้หาเงินจากการตื้อ แต่หาเงินจากการ 'แก้ปัญหา' และ 'มอบความมั่นคง' ให้ผู้คน |
| Data-Driven | ทุก Presentation คือข้อมูลสำหรับพัฒนา ใช้ AI วิเคราะห์ Transcript เสมอ |

## **LAPS Framework — ภาพรวมระบบ**

| ----- | ----- | ----- | ----- |

## **4 Rules — กฎที่ห้ามลืม**

| ⚡ Rule 1: Money Loves Speed เมื่อได้ Lead มาแล้ว ต้องติดต่อกลับภายใน 1 นาที (หรือเร็วที่สุด) ความไวคือการให้เกียรติความสนใจของลูกค้า — ยิ่งรอนาน โอกาสยิ่งเย็นลง |
| :---- |

| 🚫 Rule 2: No Stagnation ถ้าตัวเลข L หรือ A ตก ห้ามข้ามไปทำ S ให้กลับไปแก้ที่ต้นท่อ (Leads) ทันที ปัญหายอดขายส่วนใหญ่คือปัญหา Lead ไม่ใช่ปัญหา Closing |
| :---- |

| 📅 Rule 3: Consistency Over Intensity เข้าพบลูกค้า 3 คนทุกสัปดาห์ตลอดทั้งปี ดีกว่าวิ่งหาลูกค้า 20 คนในอาทิตย์เดียวแล้วหายไป 2 เดือน จังหวะสร้างความมั่นใจ ความมั่นใจสร้างยอดขาย |
| :---- |

| 📊 Rule 4: Data-Driven Improvement ใช้ AI วิเคราะห์ Transcript การคุยเสมอ เพื่อหาจุดอ่อนใน 'Golf Bag' ของเรา ทุกการเจอลูกค้าคือข้อมูลที่รอนำไปพัฒนา |
| :---- |

## **🧘 Mental System — ระบบจิตใจก่อนลงสนาม**

| 🌅 Morning Affirmation — พูดทุกเช้าก่อน Calling Session ฉัน: "วันนี้ฉันไม่ได้ออกไปขายประกัน — ฉันออกไปหาคนที่ต้องการความมั่นคง แล้วนำมันไปให้เขา" — หยุด 3 วิ หายใจลึก — ฉัน: "ทุก 'ไม่' ที่ฉันได้ยินวันนี้ คือข้อมูลที่ช่วยให้ฉันพูดได้ดีขึ้นในวันพรุ่งนี้" — หยุด 3 วิ — ฉัน: "ฉันตั้งใจจะ Touch \[ระบุตัวเลข\] คนวันนี้ — ไม่ว่าผลจะออกมายังไง ฉันทำครบ" |

## **2.1 Referral System — ระบบขอรายชื่อใหม่**

Timing ที่ดีที่สุด: (1) ทันทีหลังลูกค้าตัดสินใจเซ็น (2) หลังลูกค้าได้รับการ Claim สำเร็จครั้งแรก

| 🎁 Referral Script 'ของเยี่ยมไข้' นิก: "พี่ครับ... ปกติถ้าเพื่อนสนิทพี่ป่วย พี่เอาอะไรไปเยี่ยมครับ?" — หยุดรอ — ให้เขาตอบ — ลูกค้า: "ก็กระเช้าผลไม้บ้าง หรือไม่ก็ซื้อของฝากไป" นิก: "ใช่เลยครับพี่ แต่พี่เห็นด้วยไหมครับว่า 'กำลังใจ ไม่ยิ่งใหญ่เท่ากำลังเงิน'?" — หยุดรอ — ให้เขาพยักหน้าหรือตอบตกลง — นิก: "จะดีกว่าไหมครับ ถ้าพี่แนะนำให้นิกรู้จักเพื่อนพี่คนนั้นในวันที่เขายังแข็งแรง เพื่อให้นิกเอา 'เงินบริษัท' ไปเตรียมไว้ให้เขาในวันที่เขาจำเป็น แทนที่เขาจะต้องควักเงินเก็บทั้งชีวิตมาจ่ายเอง" — หยุด 3 วิ — ให้ภาพในหัวเขาเกิดขึ้น — นิก: "พี่พอนึกออกไหมครับว่าเพื่อนคนไหนที่พี่รักและอยากให้เขามีสวัสดิการดีๆ แบบพี่?" — หยุด 8-10 วิ — ห้ามพูดแทรก ให้เขาคิดอย่างเต็มที่ — |

## **3.1 โครงสร้างการโทรนัด — 6 Steps**

| Step | ชื่อ | เป้าหมาย | เวลา |
| ----- | ----- | ----- | ----- |
| 1 | Name | แนะนำตัว — ให้เขารู้ว่าคุยกับใคร | 5 วิ |
| 2 | Ask Permission | ขอเวลา 1-2 นาที — ลดการ์ดทันที | 5 วิ |
| 3 | Reaffirm Relevance | บอกที่มา — ทำไมถึงโทรหาเขา | 10 วิ |
| 4 | Hook Pitch | MANHA Check \+ บอกว่าช่วยอะไรได้ | 30-45 วิ |
| 5 | Low Pressure Promise | ยืนยันว่าปฏิเสธได้ทันที | 10 วิ |
| 6 | Commitment | ปิดด้วย 2 ทางเลือก | 15 วิ |

## **3.2 บทโทรนัดเต็ม — กลุ่ม A (สนิท)**

| 📱 Line Message — ส่งก่อนโทร (กลุ่ม A) นิก: "สวัสดีครับพี่ \[ชื่อ\] 😊 นิกนะครับ ช่วงนี้เป็นยังไงบ้างครับ?" นิก: "ว่างๆ นิกอยากโทรคุยด้วยซักครู่นึงได้ไหมครับ? มีอัปเดตชีวิตอยากเล่าให้ฟัง" — รอให้เขาตอบก่อน — ถ้าตอบว่าโทรได้ ให้โทรเลย — |
| :---- |

| 📞 บทโทรศัพท์เต็ม — กลุ่ม A นิก: "สวัสดีครับพี่ \[ชื่อ\] นิกนะครับ รบกวนเวลาสัก 1-2 นาที พี่พอสะดวกคุยไหมครับ?" — หยุดรอ — ให้เขาตอบ — ลูกค้า: "ได้เลยครับ / อยู่ครับ ว่าไงดี" นิก: "ขอบคุณครับพี่ เป็นไงบ้างครับช่วงนี้ \[ถามเรื่องงาน/ครอบครัว/สิ่งที่เห็นใน Social สั้นๆ\]" — หยุดรอ — ฟัง Small Talk 1-2 ประโยค — นิก: "ดีเลยครับพี่ ที่นิกทักมาวันนี้นอกจากจะคิดถึงแล้ว พอดีนิกมีเรื่องจะมาอัปเดตชีวิตนิดนึงครับ ตอนนี้นิกขยับมาทำงานด้าน 'ที่ปรึกษาทางการเงินและตัวแทนประกันชีวิต' ที่ AIA เต็มตัวแล้วครับ" — หยุด 2 วิ — นิก: "พี่พอจะเคยคุยหรือมีที่ปรึกษามาช่วยดูแลเรื่องการวางแผนแล้วหรือยังครับ?" — MANHA Check — หยุดรอ — |

## **3.3 บทโทร Referral — กลุ่ม B (มีคนแนะนำมา)**

| 📞 บทโทร Referral เต็ม นิก: "สวัสดีครับ ขอโทรหาคุณ\[ชื่อลูกค้า\]ได้เลยไหมครับ? นิกนะครับ รบกวนเวลาสัก 1-2 นาที พี่พอสะดวกคุยไหมครับ?" — หยุดรอ — ลูกค้า: "ได้เลยครับ" นิก: "ขอบคุณครับพี่ พอดีนิกได้เบอร์พี่มาจากพี่\[ชื่อผู้แนะนำ\]ครับ เขาบอกว่าพี่\[ชื่อลูกค้า\]กำลัง\[ระบุ Life Event\] พี่\[ชื่อผู้แนะนำ\]เลยแนะนำให้นิกทักมาทำความรู้จักครับ" — หยุด 2 วิ — ให้เขา Connect ชื่อผู้แนะนำ — นิก: "ตอนนี้นิกทำงานด้านที่ปรึกษาทางการเงินและตัวแทนประกัน AIA ครับ ไม่ทราบว่าพี่พอจะมีที่ปรึกษาดูแลเรื่องแผนส่วนตัวอยู่แล้วหรือยังครับ?" — หยุดรอ — MANHA Check — |

## **3.5 Objection Handling — 6 ข้อโต้แย้งการโทรนัด**

| 🔄 ระบบ Feel-Felt-Found-Close (1) เห็นใจ → (2) คนอื่นก็รู้สึกแบบนี้ → (3) แต่พบว่า → (4) ปิดนัด |
| :---- |

| ❌ OBJ 1: 'ยุ่งมาก / ไม่มีเวลา / ไว้ก่อนนะ' Feel: เข้าใจเลยครับพี่ คนทำงานระดับพี่ไม่มีใครว่างสำหรับเรื่องสวัสดิการหรอกครับ Felt: พี่งานยุ่งแบบนี้แหละครับ นิกถึงอยากเข้าไปช่วย 'ประหยัดเวลา' ให้พี่ Found: นิกไม่อยากให้ความเกรงใจของนิก มาทำให้พี่ต้องเสียเวลามานั่งไล่ดูข้อมูลพวกนี้เองในทีหลังครับ Close: นิกขอเวลาสั้นๆ 15 นาที นิกยินดีไปหาพี่ถึงที่เลยครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |
| :---- |

| ❌ OBJ 2: 'มีตัวแทนดูแลอยู่แล้ว / ทำไว้เยอะแล้ว' Feel: เข้าใจเลยครับพี่ แปลว่าพี่วางแผนมาดีมากและเตรียมตัวไว้พร้อมมากเลยครับ Felt: ลูกค้าส่วนใหญ่ของนิกที่เตรียมตัวไว้ดีแบบพี่ ตอนแรกก็รู้สึกว่าข้อมูลน่าจะครบถ้วนดีอยู่แล้วครับ Found: แต่พอได้ลองทำสรุปสิทธิ์ประโยชน์รวมหน้าเดียวแล้ว พี่ๆ พบว่าช่วยให้บริหารแผนหลายเล่มได้ง่ายขึ้นเยอะครับ Close: นิกขอเวลาสั้นๆ 15 นาที เข้าไปช่วยสรุปข้อมูลรวมให้พี่เก็บไว้ครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |
| :---- |

| ❌ OBJ 3: 'ส่งข้อมูลมาใน Line ก่อนได้ไหม?' Feel: เข้าใจเลยครับพี่ พี่อยากประหยัดเวลาและอยากดูข้อมูลเบื้องต้นก่อนใช่ไหมครับ Felt: ตัวนิกเองตอนแรกก็อยากส่งให้ทาง Line ครับ แต่พบว่าข้อมูลสวัสดิการมันเป็นเรื่องเฉพาะตัวของแต่ละคนมากจริงๆ Found: ถ้านิกส่งข้อมูลกลางๆ ไป พี่อาจเสียเวลาอ่านและไม่ตรงจุด นิกเลยอยากเข้าไปช่วยสรุปใน 15 นาที Close: นิกขอเวลาสั้นๆ 15 นาที เข้าไปแนะนำตัวและสรุปให้พี่ฟังครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |
| :---- |

| ❌ OBJ 4: 'อย่ามาขายนะ / ไม่อยากทำเพิ่มแล้ว' Feel: เข้าใจความกังวลของพี่เลยครับ พี่ไม่อยากมีความกดดันเรื่องต้องซื้ออะไรเพิ่มตอนนี้ใช่ไหมครับ Felt: ลูกค้าคนสำคัญของนิกหลายท่านก็เคยรู้สึกกังวลแบบนี้ครับ Found: แต่จริงๆ งานของนิกคือการส่งมอบข้อมูลครับ ถ้าพี่ดูสรุปแล้วรู้สึกว่ายังไม่จำเป็น พี่ปฏิเสธนิกได้ทันทีเลยครับ Close: นิกขอเวลาสั้นๆ 15 นาที ไปส่งเอกสารสรุปสิทธิ์สั้นๆ ครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |
| :---- |

| ❌ OBJ 5: 'มีตัวแทนคนอื่นสรุปให้แบบนี้อยู่แล้ว' Feel: ดีเลยครับพี่ แปลว่าพี่ให้ความสำคัญกับเรื่องสวัสดิการนี้มากเลยครับ Felt: จริงๆ ลูกค้าของนิกส่วนใหญ่ก็มีตัวแทนดูแลอยู่แล้ว แต่เหตุผลที่เขาเลือกคุยกับนิกเพิ่ม เพราะมันทำให้เกิด 'การแข่งขันด้านบริการ' ครับ Found: ถ้านิกได้เข้าไปสแตนบายดูแลพี่อีกคน วันที่เกิดเหตุฉุกเฉินแล้วคนหนึ่งไม่ว่าง พี่จะยังมีนิกคอยดูแลเรื่อง Claim ให้ทันที Close: นิกขอเวลาสั้นๆ 15 นาที เข้าไปแสดงความเป็นมืออาชีพให้พี่เห็นก่อนครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |
| :---- |

| ❌ OBJ 6: 'ไม่มีเงิน / เศรษฐกิจไม่ดี' Feel: เข้าใจเลยครับพี่ ช่วงนี้ใครๆ ก็กังวลเรื่องการบริหารกระแสเงินสดกันทั้งนั้นครับ Felt: พี่ๆ หลายท่านที่นิกดูแลอยู่ ตอนแรกก็รู้สึกกังวลเหมือนกันว่าเศรษฐกิจแบบนี้อาจเป็นการเพิ่มภาระ Found: แต่พอได้ลองมาสรุปสิทธิ์ประโยชน์กันจริงๆ พี่ๆ พบว่ามันกลับช่วยให้ 'อุดรอยรั่วทางการเงิน' และลดค่าใช้จ่ายซ้ำซ้อนลงได้เยอะครับ Close: นิกขอเวลาสั้นๆ 15 นาที นิกยินดีไปหาพี่ถึงที่เลยครับ พี่สะดวกเป็น \[วันธรรมดาช่วงเย็น\] หรือ \[วันหยุดช่วงบ่าย\] ดีครับ? |
| :---- |

## **3.6 Message Templates — หลังโทรนัดสำเร็จ**

| 📱 Confirmation Message — ส่งทาง Line ทันทีหลังวางสาย สวัสดีครับพี่ \[ชื่อลูกค้า\] นิกนะครับ ขอบคุณพี่มากครับที่สละเวลาคุยกันเมื่อสักครู่ 📋 สรุปนัดหมาย: 📅 วัน: \[ระบุวัน/วันที่\] ⏰ เวลา: \[ระบุเวลา\] 📍 สถานที่: \[ระบุสถานที่ หรือแนบพิกัด Google Maps\] พี่ไม่ต้องเตรียมอะไรยุ่งยากเลยนะครับ แค่เตรียมเล่มกรมธรรม์เก่าหรือข้อมูลสวัสดิการบริษัทไว้ใกล้มือก็พอครับ 🙏 |

## **3.7 Student to Parent Bridge — เพื่อนสู่ที่ปรึกษา (ใหม่)**

| 🎓 บทนี้สำหรับใคร? สำหรับตัวแทนที่เป็นนักศึกษาหรือวัยรุ่น ที่ต้องการใช้เพื่อนเป็นสะพานในการนัดหมายผู้ปกครอง เป้าหมายหลัก: เปลี่ยนสถานะจาก 'เพื่อน' เป็น 'ที่ปรึกษา' ก่อน แล้วค่อยต่อยอดไปหาครอบครัวเพื่อน กุญแจสำคัญ: ต้องให้เพื่อน 'เห็นคุณค่า' ของงานเราก่อน ไม่ใช่แค่ขอให้ช่วยบอกพ่อแม่ |
| :---- |

### **ขั้นตอนที่ 1 — เปลี่ยนสถานะกับเพื่อน**

| 💡 Mindset ก่อนคุยกับเพื่อน อย่าทำตัวเหมือน 'ขอความช่วยเหลือ' — ทำตัวเหมือน 'แบ่งปันโอกาส' ให้ครอบครัวเพื่อน เพื่อนจะยินดีช่วยเมื่อเขา 'เข้าใจ' ว่าสิ่งที่เราทำมีคุณค่าจริง ไม่ใช่แค่ขายของ ใช้ความเป็นเพื่อนให้เป็นประโยชน์ — เพื่อนพูดกับพ่อแม่ได้มีน้ำหนักกว่าคนแปลกหน้า 100% |
| :---- |

| 💬 บทคุยกับเพื่อนสนิท — เปิดเรื่องงานใหม่ นิก: "เฮ้ \[ชื่อเพื่อน\] ขอคุยด้วยนิดนึงได้มั้ย? ไม่นานหรอก 5 นาทีพอ" — รอให้เพื่อนพร้อม — นิก: "นิกทำงานที่ AIA มาสักพักแล้ว และเริ่มเข้าใจแล้วว่ามันไม่ใช่แค่การขายประกัน มันคือการวางแผนการเงินให้ครอบครัวคนจริงๆ" — หยุด 1 วิ — นิก: "เห็นข่าวไหมช่วงนี้ที่มีคนป่วยหนักแล้วครอบครัวล่มสลายเพราะไม่มีอะไรรองรับเลย? นิกเห็นเคสแบบนี้บ่อยมากในงาน" — หยุดรอให้เพื่อนแสดงความเห็น — เพื่อน: "อ๋อ เห็นบ้าง / ได้ยินบ้าง" นิก: "นั่นแหละ งานของนิกคือไปช่วยให้ครอบครัวคนไม่ต้องเจอสถานการณ์แบบนั้น นิกอยากขอความช่วยเหลือจากแกหน่อยนึงได้มั้ย?" |
| :---- |

### 

### **ขั้นตอนที่ 2 — เปิดเผยผลกระทบ (Emotional Bridge)**

| ❤️ บทพูดเรื่องผลกระทบต่อครอบครัว นิก: "\[ชื่อเพื่อน\] แกเคยคิดบ้างมั้ยว่า ถ้าวันหนึ่งพ่อหรือแม่แกเกิดอะไรขึ้น แบบไม่มีใครคาดคิด ชีวิตของแกและที่บ้านจะเปลี่ยนไปยังไง?" — หยุด 2 วิ — ให้เพื่อนคิด — เพื่อน: "ก็... คงลำบากนะ" นิก: "ใช่เลย แกรู้จักดีกว่านิกว่าความฝันของแกคืออะไร เรียนต่อ ทำงานดีๆ ดูแลครอบครัว แต่ทุกอย่างนั้นมันตั้งอยู่บนเงื่อนไขที่ว่า เสาหลักของบ้านต้องยังอยู่และยังทำงานได้" — หยุด 2 วิ — นิก: "ถ้าเสาหลักหักวันนี้ แล้วไม่มีอะไรรองรับเลย ไม่ใช่แค่ครอบครัวที่ลำบาก แต่ความฝันของแกก็ต้องหยุดไปด้วย ไม่ว่าจะเป็นเรื่องเรียน เรื่องอนาคต หรือสิ่งที่แกตั้งใจไว้" — หยุด 3 วิ — ให้ภาพนั้นนั่งในหัวเพื่อน — นิก: "นิกไม่ได้พูดเพื่อทำให้กลัว แต่พูดเพราะอยากให้ครอบครัวแกมีความมั่นคงก่อนที่มันจะสายเกินไป" |
| :---- |

### **ขั้นตอนที่ 3 — ขอให้เพื่อนเป็นตัวกลาง**

| ⚠️ สิ่งที่ต้องทำก่อนขอให้เพื่อนช่วย ให้เพื่อน 'เห็นด้วย' กับสิ่งที่พูดไปก่อนเสมอ อย่าเร่งขั้นตอนนี้ ถามเพื่อนว่าเขา 'โอเค' กับสิ่งที่นิกทำไหม ก่อนขอให้ช่วยแนะนำพ่อแม่ ให้เพื่อนรู้สึกว่าเขาเป็น 'คนที่ช่วยดูแลครอบครัวตัวเอง' ไม่ใช่แค่ช่วยนิกขาย |
| :---- |

| 🤝 บทขอให้เพื่อนช่วยนัดหมายผู้ปกครอง นิก: "นิกอยากขอความช่วยเหลือจากแกจริงๆ นะ แต่ขอถามก่อนว่าแกรู้สึกยังไงกับเรื่องที่เราคุยกันบ้างมั้ย?" — หยุดรอ — ให้เพื่อนแสดงความเห็นก่อน — เพื่อน: "ก็รู้สึกว่าสำคัญนะ / คิดว่ามีประโยชน์" นิก: "ดีเลย ถ้าแกเห็นว่ามันมีประโยชน์ นิกอยากขอแค่หนึ่งอย่างเลย คือแกช่วยแนะนำนิกให้รู้จักกับพ่อหรือแม่แกได้มั้ย? แบบว่าช่วยบอกแกก่อนสั้นๆ ว่านิกจะไปทำอะไร เพื่อให้แกรู้สึกว่าเป็นการตัดสินใจของแกเอง ไม่ใช่ถูกบังคับ" — หยุดรอ — ห้ามพูดแทรก — เพื่อน: "ได้ แต่ไม่รู้ว่าพ่อแม่จะว่างไหม / โอเค ลองดู" นิก: "ขอบคุณมากเลยนะ แกแค่บอกว่า 'มีเพื่อนอยากมาแนะนำตัวและช่วยเช็กสวัสดิการให้ครอบครัว ไม่มีข้อผูกมัดอะไร' แค่นั้นเองครับ นิกทำส่วนที่เหลือเองได้เลย" — หยุด 1 วิ — นิก: "แล้วพ่อแม่แกสะดวกช่วงไหนมากกว่ากันครับ วันธรรมดาช่วงเย็น หรือวันหยุดช่วงเช้า?" — รอให้เพื่อนตอบ แล้วล็อควันทันที — |
| :---- |

### 

### **ขั้นตอนที่ 4 — เตรียมเพื่อนก่อนวันนัด**

| 📋 สิ่งที่ต้องบอกเพื่อนก่อนวันนัด นิก: "\[ชื่อเพื่อน\] ก่อนวันที่นิกจะไปเจอพ่อแม่แก ขอฝากบอกแกก่อนสั้นๆ นะ" 1\. บอกพ่อแม่ว่า: 'เพื่อนจะมาช่วยตรวจสอบสวัสดิการที่มีอยู่ เพื่อให้รู้ว่าครอบคลุมแค่ไหน' 2\. ไม่ต้องพูดว่า 'มาขาย' เพราะงานจริงๆ ของนิกคือมาสรุปข้อมูลให้ก่อน 3\. ถ้าพ่อแม่แกถามว่าต้องซื้ออะไรไหม ให้บอกว่า 'แค่ฟังข้อมูลก่อน ไม่มีข้อผูกมัด' 4\. วันนั้นถ้าแกอยู่ด้วยได้จะดีมาก เพราะแกจะเป็นคนที่แก่แม่แกไว้ใจมากที่สุด — หยุด 1 วิ — นิก: "ขอบคุณมากนะ แกช่วยครอบครัวตัวเองได้เยอะมากเลยในวันนี้ครับ" |
| :---- |

### **กรณีพิเศษ — เพื่อนลังเล / กลัวพ่อแม่ไม่ยินดี**

| 🔄 Objection จากเพื่อน: 'กลัวพ่อแม่ไม่โอเค / ไม่กล้าบอก' เพื่อน: "กลัวพ่อแม่จะคิดว่านิกพาคนมาขายของ" นิก: "เข้าใจเลย แต่ลองคิดดูนะ ถ้าแกรู้ว่ามีอะไรที่ช่วยป้องกันครอบครัวได้ แล้วแกไม่บอก วันที่มันเกิดขึ้นจริง แกจะรู้สึกยังไง?" — หยุด 2 วิ — นิก: "แกไม่ต้องขาย แกแค่บอกพ่อแม่ว่า 'เพื่อนอยากมาช่วยเช็กให้' แค่นั้น ส่วนที่เหลือนิกทำเองได้ เพื่อนบอกพ่อแม่ว่าไว้ใจนิกได้ก็พอ" |
| :---- |

| 🔄 Objection จากเพื่อน: 'พ่อแม่มีประกันแล้ว' เพื่อน: "พ่อแม่มีประกันอยู่แล้วนะ" นิก: "ดีมากเลย แต่รู้มั้ยว่าคนส่วนใหญ่ที่มีประกันอยู่แล้วมักไม่รู้ว่ามันครอบคลุมอะไรบ้าง พอถึงเวลาใช้จริงถึงรู้ว่าไม่พอ นิกแค่อยากไปช่วยสรุปให้เห็นภาพชัดขึ้น ไม่ได้ไปเพิ่มภาระ" |
| :---- |

## **4.5 Insights — บทเล่าเรื่องตาม Persona (6 แบบ)**

| 💡 วิธีใช้ เลือก Insight ให้ตรงกับ Persona ที่สรุปได้จากการถาม 3P — ใช้เวลา 90 วินาที ไม่เกิน 3 นาที |
| :---- |

| 💼 \#1 นักลงทุน / HNW ถ้ามีเหตุฉุกเฉินให้ต้องใช้เงินสดหลักล้านกะทันหัน ในวันที่ตลาดหุ้นผันผวน เราจะตกอยู่ในสถานะที่ 'เสียเปรียบตลาด' ทันที — ถูกบังคับให้ขายของในราคาขาดทุน เพียงเพราะขาดสภาพคล่องเงินสด |
| :---- |

| 🏢 \#2 เจ้าของธุรกิจ ตัวพี่คือฟันเฟืองหลักของระบบการเงินทั้งหมด เมื่อรายได้จากธุรกิจสะดุด แต่ค่าใช้จ่ายคงที่ยังไม่หายไปไหน ธุรกิจที่สร้างมาอาจต้องถอยหลักกลับเริ่มใหม่เพียงเพราะระบบการเงินส่วนตัวกับบริษัทมันแยกกันไม่ออก |
| :---- |

| 👔 \#3 พนักงานประจำ สวัสดิการบริษัทคือ 'สวัสดิการติดโต๊ะ' บริษัทออกแบบมาเพื่อให้พี่หายดีแล้วกลับมาทำงานได้เร็วที่สุด ทันทีที่พี่ลุกจากโต๊ะนั้น รายได้และสวัสดิการจะหายไปทันที |
| :---- |

| 💻 \#4 Freelance / นายตัวเอง แผน 20 ปีที่ตั้งเป้าไว้ ตั้งอยู่บนเงื่อนไขที่อันตราย คือต้องภาวนาให้โลกใจดีตลอด 20 ปีนั้น พี่กำลังฝากชีวิตไว้กับ 'ดวง' ที่ควบคุมไม่ได้เลย |
| :---- |

| 👨‍👩‍👧 \#5 หัวหน้าครอบครัว ถ้าพรุ่งนี้เวลาหาเงินของพี่ถูกตัดจบลงกะทันหัน แผนที่ตั้งเป้าจะส่งน้องเรียนจนจบ หรือมีมรดกให้ครอบครัว จะเหลือเพียงมูลค่าเงินออมไม่กี่ปีที่ไม่เคยพอสำหรับชีวิตของคนที่เหลืออยู่ |
| :---- |

| 💔 \#6 ผ่านประสบการณ์เลวร้ายด้านสุขภาพ สิ่งที่พี่เห็นมากับตา มันทำให้พี่รู้ดีกว่าใครว่ามันหนักแค่ไหน ทั้งสำหรับคนที่ป่วย และสำหรับคนที่ต้องดูแลเขา สิ่งที่นิกทำได้ตอนนี้ คือทำให้แน่ใจว่าคนที่พี่รักจะไม่ต้องเจอแบบเดิม |
| :---- |

## **4.6 Closing Objections — 8 ข้อโต้แย้งเมื่อจะปิดการขาย**

| 🔄 ระบบ Agree → Trigger → Metaphor → Close ทุกครั้ง |
| :---- |

| 🔄 'ขอกลับไปคิดดูก่อน' Agree: จริงพี่ ควรใช้เวลาคิดให้ชัวร์ครับ เพราะนี่คือเงินพี่และความมั่นคงของที่บ้าน Trigger: แต่พี่... ระหว่างที่พี่กลับไปนอนคิด ไอ้ความเสี่ยงมันไม่ได้หยุดพักร้อนไปกับพี่ด้วยนะพี่ Metaphor: วันนี้เซ็นจองสิทธิ์ Lock ความคุ้มครองไว้ก่อน พอเล่มกรมธรรม์ถึงมือพี่ มีเวลาทบทวนฟรีๆ อีก 15 วัน (Free Look) Close: ไปนอนคิดแบบที่มีความคุ้มครองกอดอุ่นๆ ดีกว่านอนคิดตัวเปล่าเนาะพี่ |
| :---- |

| 💸 'เบี้ยแพง / ไม่มีเงิน' Agree: เข้าใจพี่ เบี้ยดูเหมือนแพงและเป็นภาระเนอะ Trigger: แต่ถ้าพี่ไม่ทำประกัน พี่กำลังเปิด 'บริษัทประกันชีวิต' ให้ตัวเองอยู่นะพี่ ถ้าเจ็บป่วยขึ้นมา พี่ต้องเป็นคนจ่ายสินไหมให้ตัวเองทั้งหมด Metaphor: สิ่งที่แพงที่สุดไม่ใช่เบี้ยครับพี่ แต่คือการ 'ไร้หลักประกัน' ในวันที่วิกฤตมาถึง Close: ใช้เงินก้อนเล็กปกป้องเงินก้อนใหญ่ดีกว่าพี่ เซ็นตรงนี้ครับ |
| :---- |

| 🏠 'เอาเงินไปผ่อนบ้านก่อนดีกว่า' Agree: เข้าใจพี่ ผ่อนบ้านเป็นภาระใหญ่และสำคัญมาก Trigger: แต่ถ้าเกิดแจ็กพอตขึ้นมา ใครจะผ่อนต่อพี่? ถ้าขาดรายได้ แบงก์ยึดบ้านทันที Metaphor: พี่อยากให้บ้านหลังนี้เป็น 'ของลูก' หรือ 'ของแบงก์' ว่ะพี่? Close: เซ็นตรงนี้เพื่อมอบบ้านปลอดหนี้ให้ลูกพี่เถอะครับ |
| :---- |

## **4.7 Two Meeting Audit System — ระบบ 2 นัด สำหรับลูกค้าที่มีกรมธรรม์หลายฉบับ (ใหม่)**

| 🔍 ทำไมต้องใช้ระบบ 2 นัด? ลูกค้าที่มีกรมธรรม์หลายฉบับมักไม่รู้ว่าตัวเองมีอะไรบ้าง หรือมันครอบคลุมแค่ไหน การอ่านกรมธรรม์ในที่นัดครั้งเดียวทำให้ข้อมูลไม่แม่นยำและลูกค้าไม่ได้ประโยชน์เต็มที่ การขอนำกรมธรรม์ไปวิเคราะห์ก่อน แสดงความเป็นมืออาชีพและสร้าง Authority ได้ดีมาก เมื่อนำกลับมาพร้อมใบสรุปที่ชัดเจน โอกาสปิดการขายในนัดสองสูงมาก |

### **นัดที่ 1 — บทสนทนาขอรับกรมธรรม์ไปวิเคราะห์**

| 💡 จุดสำคัญในนัดแรก เน้น Rapport และ 3P Questions ก่อน — อย่าขอกรมธรรม์ทันทีที่นั่งลง ให้ลูกค้ารู้สึกว่าเราขอไปเพื่อ 'ช่วยเขา' ไม่ใช่เพื่อหาจุดขาย อธิบายความปลอดภัยในการเก็บรักษาเพื่อลดความกังวล |
| :---- |

| 📋 บทพูดขอรับกรมธรรม์ตัวจริง — หลัง Rapport และ 3P นิก: "พี่ครับ จากที่คุยกันมา นิกอยากช่วยพี่ทำสิ่งหนึ่งที่จะมีประโยชน์มากๆ เลย" — หยุด 1 วิ — นิก: "นิกอยากขอรับกรมธรรม์ของพี่ทุกเล่มที่มีอยู่ไปวิเคราะห์ให้ละเอียดครับ เพื่อจัดทำ 'ใบสรุปสวัสดิการ' ให้พี่เห็นภาพรวมทั้งหมดในหน้าเดียว" — หยุดรอให้เขาตอบสนอง — ลูกค้า: "ได้เลยครับ / แต่กังวลเรื่องเอกสารนะ" นิก: "เข้าใจเลยครับพี่ เอกสารพวกนี้สำคัญมาก นิกขออนุญาตบอกขั้นตอนที่นิกจะดูแลให้ชัดเจนนะครับ" |
| :---- |

| 🔒 บทอธิบายความปลอดภัยในการเก็บรักษาเอกสาร นิก: "กรมธรรม์ของพี่จะอยู่ในความดูแลของนิกโดยตรงครับ นิกจะเก็บไว้ในแฟ้มเอกสารปิดสนิท ไม่มีใครเข้าถึงได้นอกจากนิก" นิก: "นิกจะถ่ายรูปหรือสแกนเก็บไว้เป็น Backup ก่อนด้วย เพื่อความปลอดภัยสองชั้นครับ" นิก: "และที่สำคัญ นิกจะนัดส่งคืนกรมธรรม์ต้นฉบับพร้อมใบสรุปสวัสดิการ ภายใน 3 วันทำการเลยครับ พี่จะได้มีเอกสารกลับคืนเร็วที่สุด" — หยุด 1 วิ — นิก: "พี่โอเคไหมครับ ถ้าให้นิกดูแลในลักษณะนี้?" — รอให้เขาตอบรับ — |
| :---- |

| 📅 บทปิดนัดสอง — ก่อนออกจากนัดแรก นิก: "ครับ งั้นนิกขอรับกรมธรรม์ไปทั้งหมดนะครับ" — รับเอกสาร — เซ็นใบรับเอกสาร ถ้ามี — นิก: "พี่ครับ นิกจะใช้เวลาประมาณ 2-3 วันในการทำใบสรุปสวัสดิการให้พี่ครบถ้วนครับ" นิก: "นิกขอนัดครั้งที่สองเลยนะครับ เพื่อส่งมอบกรมธรรม์คืนพร้อมใบสรุปที่นิกทำมาให้ พี่สะดวกเป็น \[ระบุวัน ห่างจากนี้ 3 วัน\] ตอน \[ระบุเวลา\] ไหมครับ?" — รอให้เขายืนยันวัน — Lock คิวทันที — นิก: "ขอบคุณมากนะครับพี่ แล้วพบกันวัน\[ระบุวัน\]นะครับ นิกจะเตรียมข้อมูลให้ครบและคุ้มค่าเวลาพี่มากที่สุดครับ" |
| :---- |

### **ระหว่างนัด — การวิเคราะห์กรมธรรม์และจัดทำใบสรุป**

| 📊 สิ่งที่ต้องทำระหว่าง 3 วัน 1\. กรอก FA Policy Audit Sheet (ดูในภาคผนวก) ให้ครบทุกช่อง 2\. ระบุ 'รอยรั่ว' คือสิ่งที่ขาดหรือไม่ครอบคลุมเมื่อเทียบกับความเสี่ยงที่ลูกค้ามี 3\. จัดทำใบสรุปสวัสดิการ 1 หน้า ที่อ่านง่าย เข้าใจได้ทันที 4\. เตรียม Solution ที่ตรงกับรอยรั่วที่พบ พร้อม 3 ขนาดทางเลือก 5\. ทบทวน Insight ที่ตรงกับ Persona ของลูกค้า เพื่อใช้ในนัดสอง |

### **นัดที่ 2 — บทส่งมอบใบสรุปและนำเสนอ Solution**

| 📦 บทเปิดนัดสอง — ส่งมอบกรมธรรม์คืนพร้อมใบสรุป นิก: "สวัสดีครับพี่ ขอบคุณที่นัดเจอกันอีกครั้งนะครับ นิกเอากรมธรรม์ต้นฉบับทุกเล่มมาคืนพี่เลยครับ ครบถ้วนตามที่รับไปทุกฉบับ" — ส่งกรมธรรม์คืนพร้อมนับให้เขาตรวจก่อน — นิก: "และนี่คือ 'ใบสรุปสวัสดิการ' ที่นิกทำมาให้พี่โดยเฉพาะครับ นิกใช้เวลาวิเคราะห์ละเอียดมากเพื่อให้พี่เห็นภาพรวมทั้งหมดในหน้าเดียว" — ส่งใบสรุปให้เขาดู — นิก: "พี่ครับ นิกขออนุญาตพาพี่เดินผ่านใบสรุปนี้สัก 5 นาทีก่อนได้ไหมครับ? เพื่อให้พี่เข้าใจภาพรวมของสวัสดิการที่มีอยู่และจุดที่นิกอยากชี้ให้เห็นครับ" |
| :---- |

| 🔍 บทอธิบายใบสรุปสวัสดิการ นิก: "จากการวิเคราะห์กรมธรรม์ของพี่ทั้งหมด \[X\] ฉบับ นิกพบว่าพี่มีความคุ้มครองดีแล้วในเรื่อง..." — ระบุจุดแข็งก่อนเสมอ เพื่อสร้างความน่าเชื่อถือ — ... "\[ระบุความคุ้มครองที่มี เช่น ค่ารักษาพยาบาล / อุบัติเหตุ\]" — หยุด 1 วิ — นิก: "แต่นิกพบจุดหนึ่งที่อยากให้พี่รับรู้ครับ เพราะมันเกี่ยวกับความเสี่ยงที่พี่เคยบอกว่ากังวลอยู่..." — เชื่อมกับสิ่งที่ลูกค้าบอกในนัดแรก — นิก: "คือตรงนี้ครับ \[ชี้ในใบสรุป\] ความคุ้มครองส่วน \[ระบุส่วนที่ขาด\] ยังไม่ครอบคลุมในกรมธรรม์ที่พี่มีอยู่ตอนนี้ครับ" — หยุด 2 วิ — ให้เขาดูและซึมซับข้อมูล — |
| :---- |
