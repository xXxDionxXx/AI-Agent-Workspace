# 📱 Mobile Editing: เทคนิค "การสร้างกล่องคอมเมนต์คำถาม" (Custom Comment Box)

> **"เปลี่ยนคำถามในแชทให้เป็นลูกเล่นคำถามสุดไวรัลลอยเด่นกลางคลิป"**  
> คู่มือการสร้างและใช้งานกล่องข้อความคำถามจำลองพรีเมียม **"Custom Comment Box"** โดยใช้เครื่องมือฟรีบนเว็บ **[tokcomment.com](https://tokcomment.com/)** โดยไม่ต้องลงทะเบียน เพื่อสร้างไฟล์ภาพ PNG โปร่งแสงสำหรับใช้เป็นภาพซ้อน (Overlay) ดึงดูดสายตาคนดูและกระตุ้นการโต้ตอบ

---

## 🎨 ทำไมเทคนิค "กล่องคอมเมนต์คำถาม" ถึงทรงพลังสำหรับช่องการเงิน?
* **กระตุ้นความน่าสนใจทันที:** คนดูโซเชียลมีเดียมักหยุดอ่านข้อความในรูปแบบ "กล่องคอมเมนต์" โดยสัญชาตญาณ
* **Q&A Authority:** วางตัวคุณ Nick เป็นผู้เชี่ยวชาญที่คอยตอบคำถามเชิงลึก (เช่น มีคนพิมพ์ถามเรื่องลดหย่อนภาษีกรรมการ แล้วตัวคุณโผล่มาเฉลยวิธีแก้ in คลิป)
* **ความเนี้ยบระดับพรีเมียม:** ได้ภาพกล่องคอมเมนต์ที่มีรูปโปรไฟล์ของคุณ Nick มีชื่อแอคเคานต์ และสามารถติ๊กเครื่องหมายยืนยันตัวตนสีน้ำเงิน (Blue Verified Check) เพื่อเพิ่มความน่าเชื่อถือ

---

## 🛠️ ขั้นตอนการสร้างและดาวน์โหลดกล่องคอมเมนต์ (Step-by-Step Creation)

คุณ Nick (หรือระบบ AI ด่านแรกในการออกแบบภาพ) สามารถทำตามสเต็ปบนมือถือหรือคอมพิวเตอร์ได้รวดเร็วทันใจดังนี้ครับ:

```
[ 1. ค้นหาเว็บ tokcomment.com ] ➔ [ 2. อัปโหลดรูปโปรไฟล์เตรียมไว้ ] ➔ [ 3. ติ๊กเครื่องหมายสีน้ำเงิน (Verified) ]
                                                                                  │
                                                                                  ▼
[ 6. นำไฟล์ PNG ไปซ้อนในคลิป ] ➔ [ 5. กดดาวน์โหลด (Download Comment) ] ➔ [ 4. พิมพ์ชื่อ User & คำถามการเงิน ]
```

### 1. เข้าใช้งานเครื่องมือฟรี
* เปิดเบราว์เซอร์แล้วเข้าสู่หน้าเว็บไซต์หลัก **[tokcomment.com](https://tokcomment.com/)** (เครื่องมือสร้างกล่องคอมเมนต์จำลองฟรียอดนิยม)
* เมื่อเข้าสู่หน้าเว็บแล้ว **"ไม่ต้องลงทะเบียนหรือกรอกอีเมลใด ๆ"** สามารถเริ่มต้นใช้งานสร้างกล่องได้ทันที


### 2. เตรียมภาพโปรไฟล์และตั้งค่าความน่าเชื่อถือ
* กดคลิกอัปโหลดภาพโปรไฟล์ (Profile Picture) ของคุณ Nick ที่เตรียมไว้
* **จุดไฮไลท์สำคัญ:** เราสามารถติ๊กเลือกเปิดใช้งาน **"เครื่องหมายติ๊กถูกสีน้ำเงิน (Blue Verified Check)"** ได้ด้วยเพื่อความพรีเมียมเสมือนจริงของไอจีทางการ

### 3. ใส่ข้อมูลบัญชีและคำถามการเงิน
* กรอกชื่อผู้ใช้งาน (Username) ตามแอคเคานต์ที่คุณชอบหรือใช้จริง
* พิมพ์ข้อความคำถามการเงินเชิงรุกที่ต้องการให้เป็นปมประเด็นในคลิป (เช่น *"เจ้าของธุรกิจมือใหม่ เสียภาษีบุคคลธรรมดาฐานสูงสุด โยกกำไรบริษัทเลี่ยงแบบถูกกฎหมายยังไงคะ?"*)

### 4. ดาวน์โหลดภาพโปร่งแสง PNG
* เมื่อตรวจเช็คข้อความตัวสะกดและรูปโปรไฟล์สวยงามเรียบร้อยแล้ว ให้กดปุ่ม **"DOWNLOAD Comment"** ด้านล่าง
* ระบบจะบันทึกส่งมอบไฟล์รูปภาพในรูปแบบ **PNG โปร่งแสง (Transparent PNG)** ออกมาทันที ซึ่งจะไม่มีพื้นหลังขาวรบกวนสายตา

## 📸 วิธีนำไปสวมในวิดีโอตัดต่อ (Video Overlay Steps)

เมื่อได้ไฟล์ PNG มาเรียบเรียงต่อใน CapCut หรือโปรแกรมตัดต่อบนมือถือ ให้ทำดังนี้:

1. กดเมนู **"คำทับซ้อน (Overlay)"** หรือ **"ภาพซ้อน"** ในโปรเจกต์คลิปพูดหลัก
2. เพิ่มไฟล์รูปกล่องคอมเมนต์ PNG ที่พึ่งดาวน์โหลดเข้ามา
3. จัดสเกลย่อขนาดเล็ก-ใหญ่ตามใจชอบ และลากไปวางไว้ในมุมสายตาที่ดี (แนะนำให้ลอยเด่นอยู่ข้างแก้ม หรือเยื้องไหล่ของคุณ Nick)
4. **💡 เคล็ดลับเพิ่มความสมจริง:**
   * หยอดเสียงประกอบ **"UI Pop"** หรือเสียงคลิกสั้น ๆ จากโฟลเดอร์ **`6-Editing/Audio/SFX/`** ทันทีในวินาทีแรกที่กล่องคอมเมนต์ปรากฏขึ้นมา
   * สามารถทำคู่ขนานร่วมกับเทคนิค **[Object-Behind-Person.md](Object-Behind-Person.md) (วัตถุอยู่ข้างหลังคน)** เพื่อให้กล่องคอมเมนต์นี้ลอยซ่อนอยู่หลังแผ่นหลังคุณ Nick ได้อย่างพรีเมียมล้ำสมัยที่สุด!
