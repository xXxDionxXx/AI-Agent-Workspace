# 📱 Mobile Editing: เทคนิค "วัตถุอยู่ข้างหลังคน" (Object Behind Person)

> **"ย้ายชาร์ตการเงิน ตารางภาษี หรือไอคอนพิเศษไปลอยเด่นอยู่ด้านหลังตัวคุณ"**  
> คู่มือการทำเทคนิค **"วัตถุอยู่ข้างหลังคน" (Object Behind Person)** ด้วยแอปพลิเคชันมือถือ (เช่น CapCut) เพื่อให้คุณ Nick สามารถสั่งงานตัดต่อ หรือพิมพ์กำกับมุมภาพส่งต่อให้ AI สวมไอเดียนี้สร้างสรรค์คอนเทนต์สีกริ๊บ ภาพหรู ได้อย่างสะดวกและจำง่ายที่สุด

---

## 🎨 ทำไมเทคนิค "วัตถุอยู่ข้างหลังคน" ถึงทรงพลังสำหรับช่องการเงิน?
* **เรียกสายตาได้อยู่หมัด:** การมีตัวเลข สเปรดชีต หรือกราฟิกขยับลอยอยู่หลังไหล่คุณ Nick ดึงดูดสายตาคนดูช่วงแรกได้ยอดเยี่ยม
* **สื่อสารได้ชัดเจนพรีเมียม:** คุณ Nick ยังคงเป็นโฟกัสหลักหน้ากล้อง โดยที่ตารางข้อมูลภาษีตัวหนา ๆ แสดงผลอยู่ด้านหลัง ไม่โดนทับหรือบังใบหน้า
* **รันงานง่ายได้ทุกที่:** ตัดต่อผ่านมือถือได้ทันใจ ไม่จำเป็นต้องใช้สตูดิโอกรีนสกรีนขนาดใหญ่หลังบ้าน

---

## 🛠️ 6 ขั้นตอนการทำเทคนิค "วัตถุอยู่ข้างหลังคน" บนมือถือ

พิมพ์สั่งงานหรือกดทำตามลำดับขั้นตอนบนมือถือได้ง่าย ๆ ดังนี้ครับ:

```
[ 1. เพิ่มคลิปหลัก Nick ] ➔ [ 2. เพิ่มวัตถุ/ภาพไว้ด้านหลัง ] ➔ [ 3. ปรับขนาดวัตถุให้พอดี ]
                                                                       │
                                                                       ▼
[ 6. เสร็จสิ้นเอฟเฟกต์พรีเมียม ] ➔ [ 5. กดสั่งลบพื้นหลัง (Auto Cutout) ] ➔ [ 4. คัดลอกคลิป Nick ทับบนสุด ]
```

### 1. นำเข้าคลิปหลัก (Import Main Clip)
* เพิ่มคลิปวิดีโอหลักที่คุณ Nick นั่งพูดหน้ากล้องโทนผิวพรีเมียม (Main Footage) ลงไปในไทม์ไลน์หลักเป็นอันดับแรก

### 2. วางภาพวัตถุ/ตารางการเงิน (Add Object Overlay)
* กดเมนูคำสั่ง **"คำทับซ้อน (Overlay)"** หรือ **"ภาพซ้อน"** จากนั้นเลือกรูปภาพหรือวัตถุกราฟิกที่คุณต้องการให้อยู่ข้างหลังคุณ Nick เข้ามา

### 3. จัดสเกลและระยะเวลาวัตถุ (Scale Object)
* ลากปรับความยาวแทร็กภาพวัตถุให้พอดีช่วงเวลาพูด และใช้นิ้วบีบ/ขยายจัดวางขนาดมุมมองวัตถุให้เล็ก-ใหญ่ตามใจชอบ

### 4. ซ้อนตัวคุณ Nick ทับด้านบนสุด (Duplicate & Re-Overlay)
* กดคัดลอก (Duplicate) คลิปหลักตัวตนของคุณ Nick แล้วกดสั่งเปลี่ยนให้ลงมาทับซ้อนอยู่แทร็กบนสุดเหนือภาพวัตถุ (กะตำแหน่งเริ่มของคลิปบน-ล่างให้ตรงกัน 100% เสมอเพื่อไม่ให้เสียงเหลื่อม)

### 5. ปล่อยพลังลบพื้นหลัง (Smart Cutout)
* จิ้มเลือกที่คลิป Nick แทร็กบนสุด เลื่อนหาเมนู **"ลบพื้นหลัง (Remove Background)"** หรือ **"Cutout"** 
* เลือกโหมด **"ลบล้างอัตโนมัติ (Auto Removal / สร้างใหม่)"** ด้านซ้ายมือ AI จะลบฉากหลังเดิมของคลิปบนสุดออกทันที
* *ผลลัพธ์ในขั้นตอนนี้:* คลิปบนสุดจะเหลือแค่ตัวตนคุณ Nick ลอยอยู่โดยไม่มีพื้นหลัง ทำให้วัตถุที่แทร็กด้านล่างโผล่ขึ้นมาลอยซ้อนอยู่ด้านหลังแผ่นหลังของคุณ Nick อย่างแนบเนียน!

### 6. ตรวจความเนี้ยบพรีเมียม (Final Polish)
* จะได้ผลลัพธ์วิดีโอเทคนิค **"วัตถุอยู่ข้างหลังคน"** อย่างหรูหรา พร้อมส่งออกลงโปรเจกต์ออนแอร์ได้ทันที

## 💡 ไอเดียการนำ "วัตถุอยู่ข้างหลังคน" ไปสวมคอนเทนต์
* **สถาปัตยกรรมภาษี:** โชว์ตารางเช็คลิสต์ลดหย่อนระดับ S-Tier ลอยอยู่หลังไหล่ Nick ขณะกำลังดีดนิ้วสั่งภาพ
* **พอร์ตสินทรัพย์ทวีคูณ:** ลอยไอคอนถุงเงิน/กระแสเงินสดขยับดุ๊กดิ๊กด้านหลังคุณแม่หรือตัว Nick ยามพูดเรื่องพลังดอกเบี้ยทบต้น
* **ตัวช่วยปิดยอด CTA:** วาง QR Code หรือภาพปกหนังสือคู่มือการเงินเล่มสวยลอยอยู่ด้านหลัง Nick ขณะเอ่ยประโยคปิดคลิปดักลีด
