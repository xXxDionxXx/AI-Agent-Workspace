# 🔊 คลังเสียงเอฟเฟกต์ระดับพรีเมียม (Master SFX Library & Guide)

คู่มือการจัดระดับเสียงและรายการเอฟเฟกต์ทั้งหมดสำหรับการสร้างวิดีโอระดับมืออาชีพ

---

## 🎚️ สูตรระดับเดซิเบลที่แนะนำ (Recommended Volume dB)

| ประเภทแทร็กเสียง | ระดับเดซิเบล (dB) | วิธีการมิกซ์เสียง |
| :--- | :--- | :--- |
| **เสียงเอฟเฟกต์ (SFX)** | **Peak ที่ -12 dB ถึง -15 dB** | ปรับเพื่อไม่ให้ดังแหลมกระแทกหูจนคนดูปัดเลื่อนหนี |
| **เสียงพูดหลัก (A-roll)** | **Peak ที่ -3 dB ถึง -6 dB** | ทำ Voice Isolation/Noise Reduction ก่อนเสมอ |
| **ดนตรีประกอบ (BG Music)** | **-22 dB ถึง -28 dB** | แผ่วอยู่ด้านหลัง ห้ามกลบเสียงพูดเด็ดขาด |

## 🧠 คู่มือการใส่เสียงประกอบระดับโปร (Audio Editing Guide)

### 💨 1. เสียงฟึ่บ (Whoosh / Swoosh)
* **การใช้งาน:** ฉากที่มีการเคลื่อนกล้องเร็ว ซูมเข้า/ออกฉับพลัน หรือเปลี่ยนคัตฉากแบบ Whip Pan
* **จังหวะการชน (Timing):** วางจุดที่มีระดับเสียงพีค (Peak Volume) ให้ตรงกับเฟรมกึ่งกลางของการเคลื่อนไหวกล้องหรือจุดเปลี่ยนฉากพอดี

### 👆 2. เสียงคลิกและป็อป (Pop & Click)
* **การใช้งาน:** ข้อความ (Text), รูปไอคอน, หรือภาพอินเสิร์ทป็อปอัปขึ้นบนหน้าจอ
* **จังหวะการชน (Timing):** จุดเริ่มต้นของเสียง (First transient) ต้องตรงกับ **เฟรมแรกสุดที่กราฟิกปรากฏขึ้นบนจอ** แบบ 1:1

### ✨ 3. เสียงเปิดเผยข้อมูล (Magic Reveal)
* **การใช้งาน:** การเปิดเฉลยข้อมูลสำคัญ เผยสมุดจดงบการเงิน หรือโชว์ผลลัพธ์บนจอ iPad
* **จังหวะการชน (Timing):** เล่นทันทีที่ข้อความสำคัญถูกไฮไลต์หรือเปิดเผยตัวเต็มที่

### 📈 4. เสียงบิลด์อารมณ์ (Riser / Suspense)
* **การใช้งาน:** การปูเรื่องเล่าขยายปัญหา (Amplifier) ทิ้งปมชวนให้ลุ้นจนหัวใจเต้น
* **จังหวะการชน (Timing):** ให้เสียงเริ่มเบา ๆ จากย่านต่ำและค่อย ๆ ไต่ระดับความดังขึ้นตามเนื้อเรื่อง จากนั้น **ตัดเงียบสนิท (Hard Cut)** ณ วินาทีก่อนที่จะพูดคีย์เวิร์ดเฉลย
