# 🧩 โครงสร้างประยุกต์: Setup ➔ Conflict ➔ Resolution ฉบับสมบูรณ์ (All 25 Formats)
> **Nick | Financetry**  
> *คู่มือการแปลงทฤษฎีการเล่าเรื่อง (Core Story Arc) ไปสวมทับลงใน Content Format ทั้ง 25 รูปแบบอย่างกว้างๆ เพื่อนำไปประยุกต์ใช้ได้กับทุกไอเดียและทุกอุตสาหกรรม*

หลักการ **Setup (ปูเรื่อง) ➔ Conflict (ปัญหา/ความขัดแย้ง) ➔ Resolution (การคลี่คลาย)** คือรากฐานของการเล่าเรื่องทุกประเภท ตารางด้านล่างนี้คือการจับคู่ (Mapping) อย่างสมบูรณ์แบบว่าฟอร์แมตทั้งหมด 25 รูปแบบควรวางโครงสร้างบทอย่างไรในภาพกว้างครับ:

---

## 🟡 1. TOFU (Top of Funnel) - สร้างการรับรู้ ดึงดูดคนนอก
*เป้าหมาย: หยุดคนแปลกหน้าด้วยปัญหาที่ทุกคนเผชิญ เล่นกับความสนใจระดับแมส*

| Content Format | Blueprint ที่เหมาะสม | โครงสร้างการเล่าเรื่องแบบกว้าง (Broad Structure) |
| :--- | :--- | :--- |
| **1. Ratings**<br>(จัดเรตติ้งสิ่งต่างๆ) | **💎 Value Script** | **• Setup:** กำหนดเกณฑ์หรือหมวดหมู่ของสิ่งที่จะนำมาให้คะแนน<br>**• Conflict:** ชี้ให้เห็นข้อเสีย ซ่อนเร้น หรือจุดบอดของตัวเลือกที่คนนิยมใช้<br>**• Resolution:** สรุปผลคะแนนและฟันธงตัวเลือกที่คุ้มค่าที่สุด |
| **2. Comparisons**<br>(การเปรียบเทียบเชิงแมส) | **💎 Value Script** | **• Setup:** นำตัวเลือก 2 สิ่งที่มีความขัดแย้งกันมาวางเทียบกัน<br>**• Conflict:** เน้นย้ำความสูญเสียหรือความยุ่งยากหากคนดูเลือกตัวเลือกที่ผิด<br>**• Resolution:** อธิบายเหตุผลที่ตัวเลือกที่ถูกต้องสามารถแก้ปัญหานั้นได้อย่างไร |
| **3. Tier Lists**<br>(จัดอันดับ S-Tier ถึง D-Tier) | **💎 Value Script** | **• Setup:** เปิดหัวข้อใหญ่ที่จะนำมาจัดอันดับทั้งหมด<br>**• Conflict:** สร้างความขัดแย้งในใจคนดูโดยการปัดสิ่งที่คนชอบไปอยู่ Tier ต่ำ พร้อมอธิบายจุดอ่อน<br>**• Resolution:** เผยโฉมสุดยอดเครื่องมือใน S-Tier พร้อมแก่นสำคัญที่ทำให้มันเหนือกว่า |
| **4. The Skit / POV**<br>(จำลองสถานการณ์) | **📖 Storytelling Script** | **• Setup:** ปูภาพสถานการณ์จำลองในชีวิตประจำวันที่คนทั่วไปเข้าถึงได้ง่าย<br>**• Conflict:** โยนตัวแปรหรือปัญหาที่สร้างความอึดอัด กระอักกระอ่วน หรือความเจ็บปวดเข้ามาแทรก<br>**• Resolution:** จบด้วยจุดหักมุม มุกตลก หรือข้อคิดที่คลี่คลายสถานการณ์นั้น |
| **5. Myth Buster**<br>(ขยี้ความเชื่อผิดๆ) | **💥 Contrarian Script** | **• Setup:** กล่าวถึงความเชื่อหรือค่านิยมกระแสหลักที่คนทั่วไปยอมรับ<br>**• Conflict:** หักล้างความเชื่อนั้นโดยชี้ให้เห็นถึงความเสียหายหรือผลกระทบด้านลบที่ตามมา<br>**• Resolution:** มอบความจริงชุดใหม่ที่ถูกต้องพร้อมวิธีการนำไปปฏิบัติ |
| **6. Fake Situations**<br>("สมมติว่าถ้า...") | **📖 Storytelling Script** | **• Setup:** กำหนดสถานการณ์สมมติที่ท้าทายและมีข้อจำกัดสูงสุด<br>**• Conflict:** เน้นย้ำถึงความกดดัน ความเสี่ยง หรือขีดจำกัดที่จะต้องเอาชนะในสถานการณ์นั้น<br>**• Resolution:** กางแผนเอาตัวรอดหรือวิธีแก้ปัญหาเป็นฉากๆ แบบเป็นขั้นเป็นตอน |
| **7. Commentary / Reaction**<br>(วิเคราะห์กระแสข่าวดัง) | **💥 Contrarian Script** | **• Setup:** เกริ่นถึงประเด็นร้อน ข่าว หรือเหตุการณ์ที่กำลังอยู่ในกระแส<br>**• Conflict:** ชี้จุดบอด หรือผลกระทบแอบแฝงที่คนทั่วไปหรือสื่อกระแสหลักมองข้ามไป<br>**• Resolution:** สรุปมุมมองและบทเรียนในฐานะผู้เชี่ยวชาญ |
| **8. Bracket Ranking**<br>(จัดอันดับท้าชน) | **💎 Value Script** | **• Setup:** กางผังการแข่งขันหรือการท้าดวลระหว่างตัวเลือกต่างๆ<br>**• Conflict:** การปะทะกันของข้อดีและข้อเสียในแต่ละรอบ สร้างความลุ้นระทึกให้ผู้ชม<br>**• Resolution:** ประกาศผู้ชนะเลิศพร้อมบทสรุปที่หนักแน่น |
| **9. Aesthetic / Photo Dump**<br>(เสพภาพเพลิน) | **📖 Storytelling Script**<br>*(Micro-Story)* | **• Setup:** สร้างมู้ดและโทนของภาพ/วิดีโอเพื่อดึงดูดความสนใจทางสายตา<br>**• Conflict:** แทรกข้อความหรือจุดตัดทางอารมณ์สั้นๆ ที่ท้าทายความคิดผู้ชม<br>**• Resolution:** ทิ้งท้ายด้วยความสงบ แรงบันดาลใจ หรือข้อคิดที่ฝังหัวคนดู |

---

## 🔵 2. MOFU (Middle of Funnel) - สร้างความเชื่อมั่นและเชี่ยวชาญ
*เป้าหมาย: โชว์ศักยภาพ แก้ปมลึกซึ้ง และเปิดเผยเบื้องหลัง*

| Content Format | Blueprint ที่เหมาะสม | โครงสร้างการเล่าเรื่องแบบกว้าง (Broad Structure) |
| :--- | :--- | :--- |
| **10. Expert Talking Head**<br>(พูดหน้ากล้องระดับลึก) | **💎 Value Script** | **• Setup:** ฮุกผู้ชมด้วยคุณค่าสูงสุดหรือความรู้เชิงลึกที่จะได้รับจากคลิปนี้<br>**• Conflict:** วิเคราะห์รากฐานของปัญหาหรือความผิดพลาดราคาแพงที่เกิดขึ้นในอุตสาหกรรม<br>**• Resolution:** มอบวิธีการแก้ปัญหาหรือโครงสร้างที่ถูกต้องแบบผู้เชี่ยวชาญ |
| **11. Green Screen**<br>(อธิบายสเปรดชีต/กราฟ) | **💎 Value Script** | **• Setup:** นำเสนอข้อมูลที่ซับซ้อน (กราฟ, บทความ, ตาราง) เป็นภาพพื้นหลัง<br>**• Conflict:** ชี้เป้าไปที่จุดวิกฤต หรือข้อมูลที่บ่งบอกถึงปัญหาและการสูญเสีย<br>**• Resolution:** ย่อยข้อมูลนั้นให้กลายเป็นแอคชั่นแพลนที่เข้าใจและทำตามได้ทันที |
| **12. Step-by-Step Tutorial**<br>(สอนจับมือทำ / Hacks) | **💎 Value Script** | **• Setup:** ประกาศเป้าหมายหรือทักษะที่คนดูจะได้ทำสำเร็จเมื่อดูจบ<br>**• Conflict:** พูดถึงอุปสรรค ความสับสน หรือจุดที่คนมักจะทำพลาดระหว่างทาง<br>**• Resolution:** สอนขั้นตอน 1-2-3 ที่ถูกต้องและเป็นทางลัด |
| **13. My Story Videos**<br>(เล่าประวัติ/จุดเปลี่ยน) | **📖 Storytelling Script** | **• Setup:** ปูภาพชีวิตหรือเป้าหมายในอดีต (จุดเริ่มต้นที่ผู้ชมสัมผัสได้)<br>**• Conflict:** เล่าถึงจุดตกต่ำ ความล้มเหลว หรืออุปสรรคที่ขวางกั้นความสำเร็จ<br>**• Resolution:** จุดตื่นรู้ที่ทำให้เกิดการเปลี่ยนแปลง และผลลัพธ์ของชีวิตในปัจจุบัน |
| **14. Day in the Life**<br>(พาทัวร์วิถีชีวิตเบื้องหลัง) | **📖 Storytelling Script** | **• Setup:** กำหนดเป้าหมายหรือกิจวัตรประจำวันที่ต้องทำในวันนั้น<br>**• Conflict:** ความวุ่นวาย ปัญหาเฉพาะหน้า หรือความเหนื่อยล้าที่เกิดขึ้นหลังบ้าน<br>**• Resolution:** การเคลียร์ปัญหา บทสรุปของวัน และสิ่งที่ได้เรียนรู้ |
| **15. Series (Build in Public)**<br>(พาเติบโตไปด้วยกัน) | **📖 Storytelling Script** | **• Setup:** ทบทวนเป้าหมายใหญ่ของซีรีส์ และเป้าหมายย่อยของตอนปัจจุบัน<br>**• Conflict:** อุปสรรค ความเสี่ยง หรือสิ่งที่ทำให้ออกนอกแผนในเป้าหมายย่อยนั้น<br>**• Resolution:** การแก้เกมเฉพาะหน้า และทิ้งปมความน่าติดตามไว้สำหรับตอนต่อไป |
| **16. Cost Breakdowns**<br>(เปิดงบ/ตัวเลขโปร่งใส) | **🚀 High-Authority Script** | **• Setup:** โชว์ผลลัพธ์สุดท้ายหรือความสำเร็จที่น่าประทับใจ<br>**• Conflict:** เปิดเผยต้นทุนที่ซ่อนอยู่ ความผิดพลาดที่ใช้เงินแก้ หรือความยากลำบากที่ไม่มีใครเห็น<br>**• Resolution:** สรุปโครงสร้างต้นทุนและผลตอบแทนที่แท้จริง (ROI) |
| **17. Retrospectives**<br>(บทเรียนจากความผิดพลาด) | **🛡️ Objection-Busting Script** | **• Setup:** ยอมรับและเปิดเผยความล้มเหลวหรือข้อผิดพลาดครั้งใหญ่ของตัวเอง<br>**• Conflict:** ถ่ายทอดผลกระทบและอารมณ์ความรู้สึกเพื่อสร้างความเชื่อมโยงกับผู้ชม<br>**• Resolution:** ถอดบทเรียนสำคัญ และบอกแนวทางป้องกันไม่ให้ผู้ชมพลาดซ้ำ |

## 🟢 3. BOFU (Bottom of Funnel) - ปิดการขาย คัดลีดพรีเมียม
*เป้าหมาย: ทลายกำแพงสุดท้ายของลูกค้า โชว์หลักฐานเชิงประจักษ์ และปิดดีล*

| Content Format | Blueprint ที่เหมาะสม | โครงสร้างการเล่าเรื่องแบบกว้าง (Broad Structure) |
| :--- | :--- | :--- |
| **18. แผนผังระบบ**<br>(วาดชาร์ต/โครงสร้าง) | **🚀 High-Authority Script** | **• Setup:** นำเสนอภาพรวมหรือเป้าหมายสูงสุดของระบบที่กำลังจะสร้าง<br>**• Conflict:** ชี้ให้เห็นถึงจุดเปราะบาง (Bottlenecks) หากไม่มีระบบนี้มารองรับ<br>**• Resolution:** กางแผนผังโครงสร้างที่อุดรอยรั่วทั้งหมด พร้อมชี้ชวนให้ใช้บริการ |
| **19. Client Case Studies**<br>(เคสความสำเร็จลูกค้า) | **🚀 High-Authority Script** | **• Setup:** แนะนำโปรไฟล์ลูกค้าและโชว์ผลลัพธ์ความสำเร็จที่จับต้องได้<br>**• Conflict:** วิเคราะห์จุดเริ่มต้นที่เลวร้าย หรือข้อผิดพลาดเดิมที่รั้งลูกค้าไว้<br>**• Resolution:** อธิบายกระบวนการ/บริการของคุณที่เข้าไปพลิกสถานการณ์นั้น |
| **20. Discovery Call Pitch**<br>(คลิปเรียกมา Audit) | **🚀 High-Authority Script** | **• Setup:** เจาะจงเรียกกลุ่มเป้าหมายที่มีความต้องการเฉพาะเจาะจง<br>**• Conflict:** ชี้ให้เห็นถึงความเสี่ยงหรือจุดบอดร้ายแรงที่พวกเขาอาจกำลังเผชิญอยู่โดยไม่รู้ตัว<br>**• Resolution:** เสนอการโทรปรึกษา (Call) เพื่อเป็นทางออกในการหาจุดบอดนั้นแบบไร้ความเสี่ยง |
| **21. Transformation**<br>(ผลลัพธ์ก่อน-หลัง) | **📖 Storytelling Script** | **• Setup:** โชว์สถานะ "ก่อนทำ (Before)" ที่เต็มไปด้วยความยุ่งเหยิงหรือไม่มีประสิทธิภาพ<br>**• Conflict:** ขยี้ให้เห็นถึงต้นทุน ความเครียด และเวลาที่สูญเสียไปกับการอยู่ในสถานะเดิม<br>**• Resolution:** โชว์สถานะ "หลังทำ (After)" ที่ลื่นไหลและสำเร็จผ่านวิธีการของคุณ |
| **22. Bad, Good, Great**<br>(เปรียบเทียบ 3 ระดับ) | **💎 Value Script** | **• Setup:** นำเสนอทางเลือกในการแก้ปัญหา 3 ระดับ<br>**• Conflict:** อธิบายว่าทำไมทางเลือกธรรมดา (Good) ถึงเป็นหลุมพรางและยังมีช่องโหว่<br>**• Resolution:** พิสูจน์ความเหนือชั้นของทางเลือกระดับสุดยอด (Great) ที่คุณนำเสนอ |
| **23. Fake Case Studies**<br>(แก้ปัญหาให้คนดัง) | **🚀 High-Authority Script** | **• Setup:** ยกตัวอย่างแบรนด์หรือบุคคลที่มีชื่อเสียงพร้อมปัญหาสมมติของพวกเขา<br>**• Conflict:** วิเคราะห์หายนะหรือความสูญเสียหากปัญหานั้นไม่ได้รับการแก้ไขอย่างถูกต้อง<br>**• Resolution:** นำเสนอกลยุทธ์ระดับพรีเมียมของคุณในฐานะผู้กอบกู้สถานการณ์ |
| **24. Q&A (Objection)**<br>(เคลียร์ข้อสงสัย) | **🛡️ Objection-Busting Script** | **• Setup:** หยิบยกความกลัว ข้อโต้แย้ง หรือคำถามที่ขัดขวางการตัดสินใจของลูกค้ามาพูดตรงๆ<br>**• Conflict:** แสดงความเข้าใจ (Empathy) และวิเคราะห์ว่าทำไมความกังวลนั้นถึงเป็นเรื่องปกติ<br>**• Resolution:** หักล้างความกลัวนั้นด้วยข้อเท็จจริง มุมมองใหม่ หรือการรับประกัน พร้อมปูทางไปสู่ CTA |
| **25. The Unboxing / ASMR**<br>(โชว์ดีเทลชิ้นงาน) | **💎 Value Script**<br>*(Visual Focus)* | **• Setup:** นำเสนอความสวยงาม หรือความรู้สึกแรกสัมผัสของสินค้า/บริการ<br>**• Conflict:** เปรียบเทียบความประณีตนี้กับความหงุดหงิดที่ได้จากสินค้า/บริการทั่วไปในตลาด<br>**• Resolution:** เจาะจงฟีเจอร์เด่นที่ช่วยขจัดความหงุดหงิดนั้น เพื่อกระตุ้นความต้องการซื้อ |
