# 🎬 คู่มือการใช้งาน LUTs (LUTs Usage Guide)

คู่มือแนะนำการใช้งานไฟล์ **3D LUT (.cube)** สำหรับการปรับแต่งสีวิดีโอ (Color Grading) เพื่อเพิ่มมู้ดและโทนให้งานวิดีโอของคุณดูเป็นมืออาชีพและน่าสนใจยิ่งขึ้น

---

## 🎨 รายละเอียดของแต่ละ LUT (LUT Descriptions)

ในแพ็กเกจนี้ประกอบด้วย LUTs ทั้งหมด 3 รูปแบบหลักที่ได้รับการออกแบบมาให้ครอบคลุมการใช้งานที่หลากหลาย:

### 1. 🌅 WARM LUT (`WARM.cube`)
* **โทนสีหลัก:** โทนสีทองอบอุ่น (Golden tones), ผิวดูอมชมพูสุขภาพดีเป็นธรรมชาติ (Soft skin tones)
* **เหมาะสำหรับ:** 
  * การเล่าเรื่อง (Storytelling / Cinematic)
  * วิดีโอแนวธรรมชาติ (Nature / Travel)
  * ถ่ายย้อนแสงสีทอง (Daylight / Golden Hour)
  * วิดีโอที่เน้นอารมณ์ความรู้สึกอบอุ่น อบอวลด้วยความโรแมนติกหรือความทรงจำ (Emotional looks)

### ❄️ 2. COLD LUT (`COLD.cube`)
* **โทนสีหลัก:** เงาสีคลีนตา (Clean shadows), โทนฟ้า/น้ำเงินสุดหรูหราและดูลึกลับ (Moody blues)
* **เหมาะสำหรับ:**
  * คอนเทนต์ไอที/เทคโนโลยี (Tech content / Unboxing)
  * วันที่มีเมฆครึ้ม หรือถ่ายในร่ม (Cloudy weather / Indoor)
  * ฉากที่มีความดราม่า ขรึม หรือดูลึกลับน่าค้นหา (Dramatic scenes)

### 🎬 3. FRESH LUT (`Fresh.cube`)
* **โทนสีหลัก:** เพิ่มความเปรียบต่างแบบภาพยนตร์ทันที (Cinematic contrast), สีสันสดใสมีชีวิตชีวา (Vibrant colors), สีผิวสมดุลไม่เพี้ยน (Balanced skin tones)
* **เหมาะสำหรับ:**
  * คอนเทนต์ VLOG ทั่วไป
  * วิดีโอไลฟ์สไตล์ (Lifestyle videos)
  * งานที่ต้องการภาพเคลียร์ใส สีสันอิ่มตัว สดใส ดูเป็นธรรมชาติ (Fresh & Energetic)

## 💻 วิธีการนำไปใช้งานในโปรแกรมต่างๆ (How to Use)

### 1. Adobe Premiere Pro
1. ไปที่เวิร์กสเปซ **Color** หรือเปิดพาเนล **Lumetri Color**
2. ในแท็บ **Basic Correction** หัวข้อ **Input LUT** -> เลือก **Browse...**
3. หรือในแท็บ **Creative** หัวข้อ **Look** -> เลือก **Browse...**
4. เลือกไฟล์ LUT (.cube) ที่ต้องการใช้งาน
5. ปรับค่า **Intensity** (ความเข้มข้น) ตามความเหมาะสมของคลิป

### 2. DaVinci Resolve
1. ไปที่หน้า **Color**
2. คลิกขวาที่พาเนล LUT หรือคลิกปุ่ม **LUTs** ที่มุมซ้ายบน
3. คลิกขวาแล้วเลือก **Open LUT Folder**
4. คัดลอกโฟลเดอร์ LUTs นี้ไปวางในโฟลเดอร์ที่เปิดขึ้นมา
5. คลิกขวาในโปรแกรม DaVinci Resolve แล้วกด **Refresh**
6. ลาก LUT มาใส่ที่ **Node** ที่ต้องการปรับแต่ง

### 3. CapCut (PC / Mobile)
1. นำเข้าคลิปวิดีโอลงในไทม์ไลน์
2. ไปที่เมนู **Adjust (ปรับแต่ง)** -> **LUT**
3. คลิก **Import (นำเข้า)** และเลือกไฟล์ `.cube` ที่ต้องการ
4. ลากวางบนวิดีโอและปรับระดับความเข้มข้น (Strength) ตามต้องการ

### 4. Final Cut Pro
1. เปิดแผง **Effects Browser** แล้วค้นหาเอฟเฟกต์ **Custom LUT**
2. ลากเอฟเฟกต์ **Custom LUT** มาใส่ในคลิปวิดีโอ
3. ในแผง **Inspector** เลือกตัวเลือก **LUT** -> **Choose Custom LUT...**
4. เลือกไฟล์ `.cube` ที่ต้องการใช้งาน

---

> [!TIP]
> **เคล็ดลับสำหรับการแต่งสี:**
> * **Exposure & White Balance First:** ก่อนใส่ LUT ควรปรับระดับแสง (Exposure) และความสมดุลแสงสีขาว (White Balance) ของคลิปวิดีโอต้นฉบับให้มีความเหมาะสมและเป็นกลางก่อน เพื่อให้ LUT แสดงสีสันได้ถูกต้องและสวยงามที่สุด
> * **Adjust Intensity:** หากรู้สึกว่าโทนสีของ LUT เข้มเกินไป ให้ลดค่าความเข้มข้น (Opacity / Intensity) ของ LUT ลงมาประมาณ **50% - 80%** เพื่อให้ได้ภาพที่ละมุนและเป็นธรรมชาติมากขึ้น
