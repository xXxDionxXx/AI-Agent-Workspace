# 📝 SCRIPT A: "แผนการเงินน่าเบื่อ" (Megaphone Style Adaptation)
> **เป้าหมาย:** ดัดแปลงโครงสร้างจิตวิทยาของสคริปต์ Megaphone AI เข้ากับ Niche ที่ปรึกษาการเงินของคุณ เพื่อแจกสิทธิ์ Zoom Call 15 นาที (คีย์เวิร์ด: **"เช็ก"**)

*   **A-roll (พูดหน้ากล้อง):** Medium Shot (ครึ่งตัว) คุณนั่งอยู่กลางเฟรม ผนังขาวข้างหลังมีไฟสะท้อนสีส้ม-น้ำเงิน

*   **Safe Zone:** ตัวหนังสือซับไตเติ้ลอยู่ในพื้นที่ปลอดภัย 50% ตรงกลางหน้าจอ (ระดับหน้าอก)

# 📝 SCRIPT B: "วิธีแก้คำโต้แย้ง 'แพงไป'" (High-Ticket Objection Script)
> **เป้าหมาย:** สคริปต์พูดฉบับภาษาไทยธรรมชาติ ดัดแปลงจากหลักจิตวิทยาการตอบรับคำโต้แย้งระดับโลก (LAPS4) เพื่อสร้างความน่าเชื่อถือให้กับตัวตนที่ปรึกษาทางการเงินรุ่นใหม่ของคุณ

### 📸 การจัดเฟรม (Composition Guide):
*   **A-roll (พูดหน้ากล้อง):** ถ่ายมุมระดับสายตา (Eye-level) ค่อนข้างชิดกล้อง (Medium Close-up) สบตาจริงจัง ไม่มี B-roll เยอะเพื่อให้คนดูโฟกัสที่ "ดวงตาและคำพูด" ของคุณเพื่อสร้างพลังในการโน้มน้าวใจ
