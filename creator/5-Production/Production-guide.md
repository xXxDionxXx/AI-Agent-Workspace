## 📌 1. One-Day Production Workflow (คลิปสั้นรันจบในวันเดียว)
1. **ขั้นที่ 1: Scrape & Idea** ค้นหาแก่นไอเดียและคลิปไวรัลในนิชผ่านเครื่องมือ เพื่อดูโครงสร้างบทและประโยคฮุกที่คนสนใจจริง
2. **ขั้นที่ 2: Scripting** เขียนบทพูดแบบ Word-for-Word และวางแผน Shot List ไปพร้อมกัน โดยเลือกรูปแบบฮุกดึงความสนใจจากคลังระบบ
3. **ขั้นที่ 3: Filming** ถ่ายทำตั้งกล้องเก็บทั้งภาพหลัก (A-Roll) และภาพประกอบ (B-Roll) รวดเดียวจบตามคู่มือกำกับภาพ
4. **ขั้นที่ 4: Post-Production** ตัดต่อ ใส่เลเยอร์ซาวด์เอฟเฟกต์และเพลงตามคู่มืออ้างอิง เกรดสี เติมซับไตเติล และส่งออกไฟล์

## 📸 2. Camera Settings & Visual Design (การตั้งค่ากล้องและสไตล์ภาพ)

เพื่อให้ได้ไฟล์ดิบที่คมชัด มีไดนามิกกว้าง และยืดหยุ่นที่สุดสำหรับนำไปปรับแต่งสีต่อ ให้ยึดเกณฑ์การตั้งค่าต่อไปนี้:

### ⚙️ การตั้งค่ากล้องถ่ายทำ (Nothing Phone 2a & DJI Options)

| หัวข้อการตั้งค่า | ค่าที่แนะนำ (Recommended Value) | หมายเหตุ / เหตุผลทางเทคนิค |
| :--- | :--- | :--- |
| **ความละเอียด (Resolution)** | **4K** | ให้ความคมชัดสูงสุดแม้จะนำไปครอปซูมภายหลัง |
| **อัตราเฟรม (Frame Rate)** | **24 fps** | (ยึดตามมาตรฐานภาพยนตร์ 24 fps เพื่ออารมณ์และสัมผัสแบบฟิล์มคลาสสิก) |
| **โหมดควบคุมแสง** | **Manual (M)** | ป้องกันแสงสว่างวูบวาบระหว่างถ่ายทำ |
| **สปีดชัตเตอร์ (Shutter Speed)** | **1/50** | รักษา Motion Blur ที่เป็นธรรมชาติ (สัมพันธ์กับกฎ 180 องศาสำหรับ 24fps) |
| **ISO** | **50 - 1,600** | พยายามรักษาให้ต่ำที่สุดเพื่อหลีกเลี่ยงสัญญาณรบกวน (Noise) |
| **การชดเชยแสง (EV)** | **-0.7** | ป้องกันแสงส่วนไฮไลท์ไหม้ (Overexposed) ช่วยเก็บรายละเอียดได้ดีขึ้น |
| **ความคมชัด (Sharpness)** | **-2** | หลีกเลี่ยงความคมแบบดิจิทัลที่ดูปลอม แล้วค่อยไปเพิ่มในขั้นตอนตัดต่อ |
| **การลดสัญญาณรบกวน (Noise Reduction)** | **-2** | เพื่อรักษาเกรนที่เป็นธรรมชาติ ไม่หลอกตา |
| **โหมดสี (Color Mode)** | **มาตรฐาน (Rec.709)** | กล้อง Nothing Phone 2a จะถ่ายเป็นขอบเขตสีมาตรฐาน Rec.709 โดยตรง |
| **ไวท์บาลานซ์ (White Balance)** | **Auto** (สำหรับ Vlogging) / **Manual** (ตั้งฟิกซ์หากถ่ายที่ร่มไฟนิ่ง) | ป้องกันสีอุณหภูมิเปลี่ยนไปมาระหว่างคลิป |

### 📸 สูตรลับ: การทำพื้นหลังเบลอสวยงามเหมือนกล้องภาพยนตร์
หากถ่ายด้วยกล้องมือถือแล้วอยากได้พื้นหลังเบลอ (Depth of Field) แบบสวยสมจริงเหมือนเลนส์พรีเมียม:
1. **จัดระยะห่าง (Distance):** ให้ตัวคุณยืน **ห่างจากฉากหลังให้มากที่สุด** และให้เลนส์กล้องมือถือ **อยู่ใกล้ตัวคุณให้มากที่สุด** (แต่ยังรักษาระยะครึ่งตัวที่สวยงามไว้ได้)
2. **ใช้โหมดบุคคล (Portrait Video):** ปรับรูรับแสงจำลอง (Aperture) ไปที่ประมาณ **f/2.0 - f/2.8** เพื่อให้เบลอกำลังสวย ไม่หลอกตาจนตัดขอบผมแหว่ง
3. **จัดแสงแยกตัวตน (Separation Light):** ใช้ไฟส่องขอบหัว/ไหล่จากด้านหลัง (Hair Light/Rim Light) เพื่อช่วยตัดขอบให้ระบบเบลอหลังของกล้องจำแนกผิวเรากับฉากหลังได้ชัดเจนขึ้น

### 🎨 ชุดสีหลักประจำแบรนด์ (Branding Color Palettes)
การคุมโทนสีตัวอักษร ซับไตเติล และกรอบภาพใน Instagram จะช่วยสร้างภาพจำ (Brand Identity) ได้ทันที เลือกใช้ 1 ใน 5 พาเลทนี้ที่สะท้อนถึงตัวคุณมากที่สุด:

| พาเลทสี (Palette Style) | รหัสสีหลัก (Hex Code) | สไตล์ความรู้สึก (Aesthetic Tone) |
| :--- | :--- | :--- |
| **1. Sleek Professional** | `#011f7b` (Dark Blue) & `#FFBA09` (Warm Yellow) | ดูน่าเชื่อถือ มั่นคงแบบสถาบันการเงินระดับสูง แต่มีความหรูหรา |
| **2. Warm Classic** | `#AB1509` (Deep Red) & `#fff7d3` (Soft Yellow) | สไตล์อบอุ่น เป็นมิตร เข้าถึงง่าย มีกลิ่นอายความคลาสสิก |
| **3. Bold Tech** | `#323232` (Dark Gray) & `#FFDB00` (Vivid Yellow) | โมเดิร์น ทันสมัย ลุย ๆ เหมาะกับวัยรุ่นหรือคนรุ่นใหม่ที่ชอบเทคโนโลยี |
| **4. Organic Natural** | `#1A1A00` (Black-Olive) & `#FFFFCC` (Creamy Yellow) | สไตล์เรียบง่าย รักโลก อบอุ่น ผ่อนคลาย เน้นเรื่องความสมดุลชีวิต |
| **5. Retro Dynamic** | `#1A0033` (Retro Purple/Black) & `#FF4500` (Orange-Red) | โดดเด่น สะดุดสายตา มีพลังขับเคลื่อนสูง สไตล์ Retro Arcade |

## 🎞️ 3. DaVinci Resolve Project Setup & Color Space Transform (CST)

ขั้นตอนภาคปฏิบัติสำหรับเริ่มต้นโครงการใหม่ใน DaVinci Resolve เพื่อลดการทำงานของเครื่องและจัดการระบบสีให้พรีเมียม:

### 🛠️ การตั้งค่าโปรเจกต์ (Project Settings)
*(ทำเฉพาะตอนสร้างโปรเจกต์ใหม่ โดยกดปุ่มฟันเฟือง ขวาล่างสุด)*

1. **หน้า Master Settings:**
   * **Timeline Resolution:**
     * *แนวนอน (YouTube):* เลือก `3840 x 2160 Ultra HD`
     * *แนวตั้ง (TikTok/Reels/Shorts):* ติ๊กถูกช่อง `Use Vertical Resolution` (เป็น `2160 x 3840`)
   * **Timeline / Playback Frame Rate:** ปรับเป็น `24` (ยึดตามมาตรฐานเฟรมเรตภาพยนตร์ 24 fps)
   * **Pixel aspect ratio:** เลือก `Square`
2. **หน้า Video Monitoring (เลื่อนลงมาหน้าเดิม):**
   * **Video Resolution:** `1920 x 1080 HD` | **Format:** `24p` | **Video bit depth:** `8 bit`
3. **หน้า Optimized Media and Render Cache:**
   * ปรับ 5 ช่องนี้ให้เป็น **Quarter** และ **H.264** ทั้งหมดเพื่อลดภาระเครื่อง:
     * Proxy media resolution ➡️ `Quarter` | Proxy media format ➡️ `H.264`
     * Optimized media resolution ➡️ `Quarter` | Optimized media format ➡️ `H.264`
     * Render cache format ➡️ `H.264`
   * ติ๊กถูกช่อง `Automatically cache transitions in user mode`
4. **หน้า Working Folders (เลื่อนลงมาล่างสุด):**
   * กด **Browse** เพื่อย้ายโฟลเดอร์ทำงานหนี OneDrive (สร้างโฟลเดอร์ใหม่นอก OneDrive ในไดรฟ์ C ตรง ๆ):
     * Proxy generation location ➡️ `C:\DaVinci_Proxy`
     * Cache files location ➡️ `C:\DaVinci_Cache`
     * Gallery stills location ➡️ `C:\DaVinci_Gallery`
5. **หน้า Color Management (เมนูด้านซ้ายมือ):**
   * **Color science:** เลือก `DaVinci YRGB`
   * **Timeline color space:** เลือก `Rec.709 Gamma 2.4`
   * **Output color space:** เลือก `Rec.709 Gamma 2.4`
   *(ตั้งค่าครบหมดแล้ว กดปุ่ม Save ขวาล่างสุด)*

### 🟢 การนำเข้าไฟล์ และทำ Proxy (ช่วยให้เครื่องลื่น)
1. ลากคลิปวิดีโอ 4K เข้ามาในหน้าต่าง **Media Pool**
2. คลุมดำหรือกด `Ctrl + A` เพื่อเลือกคลิปวิดีโอทั้งหมด
3. คลิกขวา บนคลิปที่เลือก ➡️ เลือกคำสั่ง **Generate Proxy Media** (รอโหลดจนเต็ม)
4. มองเมนูด้านบนสุดของจอ เลือก **Playback ➡️ Proxy Handling ➡️ ติ๊กเลือก Prefer Proxies** (ไอคอน Proxy สีเหลือง/เขียว จะแสดงบนไทม์ไลน์ภาพทำงานได้สมูทขึ้น)

### 🔄 การ Grading คลิปจาก Nothing Phone 2a (ไม่มีการแปลงสี CST)
เนื่องจากกล้อง Nothing Phone 2a ถ่ายในขอบเขตสีมาตรฐาน **Rec.709** โดยตรงอยู่แล้ว ไฟล์จึงไม่ใช่ไฟล์ Log ที่จืดและแบน:
* **ไม่ต้องใช้ CST (Color Space Transform):** คุณไม่ต้องลากเอฟเฟกต์ CST มาแปลงสีเหมือนกล้อง DJI/โดรน
* **ย้อมมู้ดแอนด์โทนสีผิวด้วย LUT ได้ทันที:** ในหน้า Color ให้คุณสร้าง Node 2 แล้วนำไฟล์ LUTs จากโฟลเดอร์ [creator/LUTS/](file:///c:/AI-Agent-Workspace/creator/LUTS/) ไปใส่ที่ Node 2 เพื่อย้อมมู้ดแอนด์โทนและสกินโทนของคลิปวิดีโอได้ตรงๆ เลย
* *(หมายเหตุ: หากในอนาคตมีฟุตเทจ DJI D-Log M ค่อยใช้เอฟเฟกต์ CST แปลงจาก Input Color Space: DJI D-Gamut / Input Gamma: Gamma 2.4 เป็น Rec.709)*

## 🎨 4. DaVinci Color Grading Nodes Layout & LUTs Application

เทคนิคย้อมสีโทนผิวสุดพรีเมียมอย่างเป็นระบบในหน้า **Color**

```text
[Node 1: Base Correction] ──(ปรับแสง/Contrast)──> [Node 2: Brand LUT] ──(ย้อมโทนและสกินโทน)
```

### 🛠️ ขั้นตอนการเกรดสีระดับ Nodes:
1. คลิกเข้ามาที่หน้า **Color** (ไอคอนวงกลมสามสีด้านล่าง)
2. กดปุ่ม `Alt + S` บนคีย์บอร์ด เพื่อสร้างกล่องสี่เหลี่ยมที่ 2 (**Node 2**) ขึ้นมาคู่กัน
3. **คลิกที่ Node 1 (กล่องแรก - ปรับผิวรองพื้นให้ได้มาตรฐาน):**
   * หากภาพมืด/สว่างไป ➡️ หมุนวงล้อ **Offset** ดึงขึ้นหรือลงให้พอดีสายตา
   * ปรับแกน **Contrast** (ใต้ชุดวงล้อสี) เพิ่มขึ้นอีกนิดเพื่อให้ภาพมีมิติมืดสว่างชัดเจน
4. **คลิกที่ Node 2 (กล่องที่สอง - ทาสีเติมแต่งแบรนด์):**
   * คลิกขวาที่ Node 2 ➡️ เลือก **LUT** ➡️ เลือกใส่ LUT ที่เตรียมไว้
5. **ทริกก็อปปี้สีไปคลิปอื่นใน 1 วินาที (Copy Grading):**
   * คลิกเลือกคลิปถัดไป (หรือคลุมดำเลือกหลายๆ คลิปที่ถ่ายมุมและแสงเดียวกัน)
   * เลื่อนเมาส์ไปชี้ที่ **คลิปแรก** ที่แต่งเสร็จแล้ว ➡️ แล้วกด **ปุ่มลูกกลิ้งตรงกลางเมาส์ (Middle Click)** สีกำแพง Node ทั้งหมดจะปลิวมาแปะใส่คลิปที่เหลือทันที

> [!TIP]
> **เคล็ดลับสำหรับการแต่งสี:**
> * **Exposure & White Balance First:** ก่อนใส่ LUT ควรปรับระดับแสงและสมดุลแสงสีขาวของคลิปวิดีโอต้นฉบับใน Node 1 ให้มีความเป็นกลางก่อน เพื่อให้ LUT แสดงสีสันได้ถูกต้องที่สุด
> * **Adjust Intensity:** หากรู้สึกว่าโทนสีของ LUT เข้มเกินไป ให้คลิกที่ Node 2 -> ไปยังหน้าต่าง Key ด้านล่าง -> ลดค่า **Key Output (Gain)** ลงมาประมาณ **0.50 - 0.80** เพื่อความละมุนเป็นธรรมชาติ

## 🔤 5. Subtitle Styling Rules (ระบบตั้งค่าเอฟเฟกต์ซับไตเติ้ล)

การออกแบบสไตล์ตัวอักษรให้อ่านง่ายและสะดุดตา เป็นสิ่งสกัดความสนใจชั้นเลิศ:

### 1. ระบบใส่ Effect ซับไตเติ้ลหลัก (Legibility Framework)
* **Shadow Effects (เงาตัวอักษร - ค่าเริ่มต้นใช้งานหลัก):** **นี่คือค่ามาตรฐานสูงสุด (Default)** สำหรับคลิปทั่วไป คลิปท่องเที่ยว วิดีโอสไตล์ Vlog และงานแนว Cinematic การใส่เงาฟุ้งสีดำเข้มบางเบา (Shadow 30-50%) จะช่วยทำให้ข้อความสีขาว/เหลืองแยกออกจากพื้นหลังได้คมชัด โดยที่ตัวอักษรยังคงความคลีน ความหรูหรา และไม่บดบังหรือรบกวนรายละเอียดของภาพวิดีโอ
* **Background Bars (แถบพื้นหลังดำ):** ใช้กับคลิปพูดหน้ากล้อง (Talking Head) ที่ต้องการเน้นข้อมูลเนื้อหาคนพูดเป็นหลัก หรือเมื่อฉากหลังมีความรก คอนทราสต์ต่ำ/สว่างสูงจนอ่านซับยาก (หลีกเลี่ยงการใช้กับคลิปวิวธรรมชาติเพราะจะบังภาพ)
* **Stroke Effects (การใส่ขอบสี):** ใช้กับคลิปโปรโมชั่น ประกาศสำคัญด่วน หรือดีลเร่งรีบ เพื่อกระแทกตาคนดูทันที (หลีกเลี่ยงการใช้กับแบรนด์หรูหราทันสมัยเพราะทำให้งานดูย้อนยุค)
* **Clean Backdrops (ซับไตเติ้ลเปล่าไร้ขอบ):** ใช้เมื่อจัดองค์ประกอบภาพใน Pre-Production เรียบร้อยแล้ว โดยถ่ายจุดที่พื้นที่วางซับมีความมืดและนิ่งสนิท ทำให้เห็นซับสีขาวได้เด่นชัดโดยตรง

### 2. จานสีฟอนต์กระตุ้นอารมณ์
* **สีส้ม:** `#ff8c55` | **สีเขียว:** `#8ffb84` | **สีฟ้า:** `#00cfc6` | **สีม่วง:** `#c3b8ff`
* **สีแดง:** `#ff4a60` | **สีขาว:** `#f8f9fa` | **สีเหลือง:** `#ffeb3b`

### 3. เทคนิค 3D Pop-Up Text (ตัวอักษรโผล่หลังคน)
สร้างมิติให้คลิปสั้นดูพรีเมียม:
1. ทำการ Duplicate คลิปหลักขึ้นมาวางทับด้านบน (เช่น วิดีโอหลักอยู่เลเยอร์ V1, เอาตัวที่ก๊อปปี้ไปวาง V3)
2. ที่คลิป V3 (ตัวบนสุด) ใช้เครื่องมือ **Object Select / Masking Tool** ทำการ Mask ตัวบุคคลออกโดยเฉพาะ
3. นำซับไตเติ้ลข้อความ (Text) มาวางไว้ที่เลเยอร์ V2 (ระหว่างกลาง)
4. ตัวหนังสือจะอยู่หลังตัวผู้พูด แต่ลอยอยู่ข้างหน้าฉากหลังทันที
5. *ทริกเสริม:* ใส่ Gaussian Blur และ Zoom บนตัวหนังสือด้วยคีย์เฟรม Transform ในจังหวะป็อปอัป

## 📐 6. Cinematic Cinematography (คู่มือกำกับภาพและมุมกล้อง)
ไทม์ไลน์การตัดต่อต้องผสมผสานระหว่าง **ขนาดภาพ (6 Shots)** และ **มุมกล้อง (3 Angles)** เพื่อสร้างไดนามิกที่หลากหลาย ไม่ให้ภาพนิ่งแช่นานเกินไป

### 📸 การประยุกต์ใช้กับภาพพูดหลัก (A-Roll Dynamics)
หลีกเลี่ยงการถ่ายภาพพูดหลัก (A-Roll) แบบมุมสายตาเดี่ยวแบบดั้งเดิมที่นิ่งน่าเบื่อตลอดทั้งคลิป โดยปรับใช้ Cinematic Matrix ในจุดเหล่านี้:
1. **Dynamic Cuts (สลับขนาดภาพระหว่างพูด):**
   * **ท่อนเกริ่น/ฮุก (Hook):** ใช้ **Mid Shot (M) + Low Angle (LA)** เพื่อเสริมความมั่นใจ ทรงพลัง
   * **ท่อนขยี้ปัญหา/ไคลแมกซ์:** ใช้ **Close-up (CU) + Eye Level (EL)** หรือคีย์เฟรมทำ **Push In (เลื่อนกล้องเข้าซูม)** เพื่อดึงคนดูให้ตึงเครียดตามในจุดสำคัญ
   * **ท่อนสรุปทางออก/ปลดล็อก:** คลายความอึดอัดด้วยการเปลี่ยนกลับมาเป็น **Mid Shot (M) + Eye Level (EL)** หรือทำ **Push Out** เลื่อนถอยหลัง
2. **Multi-Angle Camera (การจัดกล้องสองมุม):**
   * หากมีสมาร์ตโฟนเครื่องเดียว ให้ทำการครอปภาพซูมในไทม์ไลน์ (เช่น ซูม 115% ในบางประโยคสำคัญ) เพื่อเปลี่ยนสลับระยะขนาดภาพระหว่าง A-Roll
   * สลับหน้ามองตรง และเบี่ยงตัว 45 องศาหันไปพูดกับกล้องตัวที่ 2 ในพาร์ทที่เล่าเรื่องส่วนตัวหรือตอบข้อซักถาม เพื่อให้เรื่องเล่ามีไดนามิกและมิติอารมณ์ที่ต่างกัน

### คลังขนาดภาพ (6 Cinematic Shots)
* **Wide Shot (W):** ใช้เปิดสถานการณ์ เห็นบรรยากาศกว้าง กำหนดพิกัดจำลองสถานที่รอบตัว
* **Mid Shot (M):** เฟรมครึ่งตัว เห็นท่าทางและการขยับมือสื่อสารชัดเจน เน้นการเล่าเรื่องและการพูด
* **Close-up (CU):** เจาะลึกใบหน้าหรือวัตถุสิ่งของ เพื่อดึงสมาธิคนดูให้โฟกัสจุดนั้นหรือเน้นอารมณ์ให้ชัดเจน
* **POV (Point of View):** มุมมองแทนสายตาผู้พูด เสมือนคนดูหลุดเข้าไปสวมบทบาทและอยู่ในเรื่องเล่าจริง
* **Push In:** กล้องเคลื่อนเข้าหาหน้า/วัตถุอย่างต่อเนื่อง เพื่อบิวด์ความกดดัน ตรึงความตื่นเต้น และล็อกสายตาในจุดสำคัญ
* **Push Out:** กล้องเคลื่อนถอยห่างออกจากจุดเดิม เพื่อคลายความตึงเครียด ทิ้งระยะห่าง หรือสร้างความรู้สึกปล่อยวางจบประเด็น

### คลังมุมกล้อง (3 Camera Angles)
* **Low Angle (LA):** เสยกล้องขึ้นเล็กน้อย เสริมความน่าเชื่อถือ มี Authority ทรงพลัง
* **Eye Level (EL):** ระนาบสายตา เพิ่มความรู้สึกจริงใจ เป็นกันเอง เชื่อมโยงง่าย
* **High Angle (HA):** กดกล้องลงต่ำ มองส่องโต๊ะทำงาน หรือเล่าพาร์ทที่ต้องการความผ่อนคลาย

### ตัวอย่างสูตรผสมมุมภาพ (Cinematic Matrix สำหรับลงไทม์ไลน์)
* **M + LA (Mid Shot + Low Angle):** ถ่ายครึ่งตัวมุมเสยเล็กน้อย ใช้ช่วงพูดประโยคฮุก หรือสรุปใจความสำคัญเพื่อเน้นความหนักแน่น น่าเชื่อถือ
* **Push In + EL (Push In + Eye Level):** กล้องค่อยๆ เลื่อนเข้าหาหน้าในระดับสายตา ใช้ช่วงขยี้ประเด็นสำคัญ หรือเน้นย้ำความจริงจัง
* **CU + HA (Close-up + High Angle):** เจาะระยะใกล้ภาพมุมกด ใช้ถ่ายฉาก Overhead ตอนเขียนไอแพด หรือกดสลับดูดีเทลอุปกรณ์บนโต๊ะคอม
* **POV (Point of View):** ถ่ายจากมุมมองสายตาเรา เช่น มุมมองตอนกำลังเดินเข้าตึกเรียน หรือยื่นมือไปเปิดสวิตช์ไฟโต๊ะคอม

### 🎬 3 เอฟเฟกต์เปลี่ยนฉากยอดฮิต (3 Editing Effects)
* **Wipe Transition (การปัดเปลี่ยนฉาก):** เดินบังหน้าเลนส์จนมืดเฟรมสนิท ตัดคลิป จากนั้นขึ้นช็อตใหม่โดยเดินหลบตัวออกจากเฟรม
* **Match Cut Reveal (การตัดแมตช์เคลื่อนไหว):** ถ่ายการสะบัดมือหรือเหวี่ยงกล้องรอบแรกแบบไม่มีของ ➔ ถ่ายครั้งที่สองโดยมีของในมือในจังหวะเดียวกัน นำมาตัดชนตรงกลางจังหวะเหวี่ยงเพื่อทำให้ของปรากฏทันที
* **Flash Teleport (การวาร์ปกระพริบแสง):** ล็อกกล้องนิ่งบนขาตั้ง ถ่ายวิดีโอตัวเองยืนตำแหน่งที่ 1 และตำแหน่งที่ 2 ➔ ตัดชนจังหวะเคลื่อนย้ายแล้วใส่คีย์เฟรมเร่ง Exposure สว่างจ้า (White Flash) เพื่อพรางรอยต่อ

## 📍 8. Production Locations (พิกัดถ่ายทำและจัดเซ็ตห้อง)
* **[อาคารระพีสาคริก มก.]:** มู้ดมินิมอล ขาว เทา โครงสร้างบันไดวนและแสงเงาตกกระทบสูง (เหมาะกับคลิปความรู้เน้นความพรีเมียม ขรึม เท่)
* **[คณะเกษตร ตึกเก่า มก.]:** มู้ดระเบียงไม้ ตึกอิฐ มีเงาเถาวัลย์และแสงลอดผ่านใบไม้ (เหมาะกับคลิปเล่าเรื่องส่วนตัว โทนฟิล์ม Warm อบอุ่น)
* **[สนามอินทรีฯ มก.]:** มู้ดเส้นลู่วิ่งสีแดงและต้นไม้สีเขียว มีพลังงานความเคลื่อนไหวสูง (เหมาะกับคอนเทนต์ไลฟ์สไตล์ กระฉับกระเฉง)
* **[ห้องนอนส่วนตัว - โซนโต๊ะคอม]:** 
  * **Setup & Visuals:** มู้ดมินิมอล โทนขาวคลีน (All-White Setup) ฉากหลังห้องเป็นผนังสีขาวสะอาดตา จัดวางโต๊ะคอมพิวเตอร์สีขาวคลีน ระยะห่างกล้องตั้งระดับสายตา (Eye-level) ประมาณ 1.2 เมตร
  * **Lighting System:** ใช้ไฟหลัก (Key Light) เป็นแสงธรรมชาตินุ่มจากหน้าต่าง (Daylight) หรือ Softbox ทำมุมเฉียง 45 องศาด้านหน้า และเปิดไฟฉากหลัง (Accent Light) สีฟ้า/น้ำเงิน ส่องยิงผนังหลังด้านซ้าย เพื่อขับให้เกิดมิติความลึก (Depth) แยกตัวผู้พูดออกจากกำแพงขาว
  * **Vibe & Color Palette:** คุมมู้ด Cinematic, Minimal, Sleek & Professional เน้นโทนสีหลักเป็นโทนเย็น (ขาว, เทา, น้ำเงิน/ฟ้าคราม) ตัดสลับสะกดสายตาด้วยคู่สีโทนร้อน (เหลืองทองคำ/ทองสว่าง)

## 📤 9. การตั้งค่าส่งออกงาน (Instagram 4K HDR Secret Export Settings)

สูตรการตั้งค่าส่งออกคลิปบน DaVinci Resolve เพื่อดักบิตเรตและคงความชัดสวยเมื่อขึ้นแพลตฟอร์ม:

* **Format:** `MP4` | **Codec:** `H.265` (หรือ HEVC)
* **Resolution:** เลือก `3840x2160 Ultra HD` (หรือแนวตั้ง `2160x3840` ตามไทม์ไลน์)
* **Frame Rate:** `24` fps (ยึดตามมาตรฐานเฟรมเรตที่ถ่ายทำเพื่อรักษาอารมณ์แบบ Cinematic)
* **Quality:** ติ๊กช่อง **Restrict to** ➡️ พิมพ์ตัวเลข **30000** หรือ **40000** Kbps (เป็นค่าความชัดที่เหมาะสมที่สุดระหว่างขนาดไฟล์และการบีบอัด)
* **Encoding Profile:** เปลี่ยนเป็น `Main 4:2:2 10-bit` (ในช่อง Profile)
* **Multi-pass encode:** ติ๊กถูกเลือก `On`
* **Advanced Settings (ล่างสุด):**
  * เอาติ๊กถูกช่อง **Bypass re-encode** ออก (Uncheck)
  * ติ๊กถูกช่อง **Force sizing to highest quality**
  * ติ๊กถูกช่อง **Force debayer to highest quality**
* กดปุ่ม `Add to Render Queue` ➡️ แล้วกดปุ่ม `Render All` เพื่อส่งออกงาน

> [!TIP]
> **เคล็ดลับขั้นสุดท้ายก่อนโพสต์ (Bypass IG Compression):**
> นำคลิปที่ได้จาก DaVinci เข้าไปในแอป **Edits app** บนมือถือ สร้างโปรเจกต์ใหม่ ใส่คลิป เลือกความละเอียด 4K, 24fps และเปิดใช้งานโหมด **Color HDR** จากนั้นทำการ Export ผ่านแอป Edits นี้จะช่วยล็อก Metadata วิดีโอให้ Instagram ยอมรับไฟล์ 4K HDR โดยตรงโดยไม่โดนบีบอัดไฟล์จนเสียดีเทล

## 🎨 10. ตารางสรุปการใช้งาน LUT, BGM และ SFX ในแต่ละคลิป (Clip-by-Clip Asset Mapping)

### 📋 หลักการเลือกใช้ทรัพยากร (General Rules):
1. **การย้อมสี (LUT Selection):**
   * **🎨 WARM LUT:** สำหรับพาร์ทเล่าเรื่อง (Daylight Storytelling) หรือโทนอบอุ่น สร้างความเชื่อใจ
   * **❄️ COLD LUT:** สำหรับท่อนคัดค้าน (Objection) หรือแสดงปัญหา (Pain Point) สร้างความดราม่า/จริงจัง
   * **🎬 FRESH LUT:** สำหรับภาพ B-Roll ที่มีสีสันสะดุดตา เพื่อเพิ่ม Contrast และสีผิวที่สดใสเป็นธรรมชาติ
2. **การจับคู่เสียงคีย์ดนตรี (Tonal SFX Key Matching):**
   * เลือกใช้ไฟล์ **Sonar Glow** ในโฟลเดอร์ `Tonal Sound Effects` ที่มี **คีย์ดนตรีตรงกับคีย์ของเพลงประกอบหลัก** เสมอ เพื่อไม่ให้เสียงเพี้ยนขัดหูคนดู

* **ธีมหลัก:** แก้ไขข้อโต้แย้ง x หักล้างดราม่า x สว่างแก้ปัญหา
* **🎨 การใช้ LUT:**
   * **A-Roll (L1 - L3, L8):** ใช้ **COLD LUT** (โทนน้ำเงินหม่น/เงาดำ เพื่อเน้นความน่ากลัวของบิลค่ารักษาพยาบาลดราม่า)
   * **B-Roll & A-Roll ช่วงหาทางออก (L4 - L7, L9):** ใช้ **FRESH LUT** (เพื่อภาพคอนทราสต์จัดจ้าน สีผิวสว่าง บ่งบอกถึงความปลอดภัยและทางสว่าง)
* **🎵 เพลงประกอบ (BGM):** `Million Dollar Baby` (คีย์ **F Minor**)
* **🔊 การใช้ SFX ประจำฉาก:**
   * **L1 (Hook):** `Reverse Playback.WAV` (เสียงสไลด์บิลย้อนกลับฉับพลัน)
   * **L3 (Pain Point):** `Deep Woosh.WAV` (เสียงทุ้มลึกเน้นย้ำความแพงร้อยเท่า)
   * **L4 (B-Roll 1):** `Woop.mp3` (เสียงกางร่มกันฝนสว่าง)
   * **L5 (B-Roll 2):** `Woosh 2.WAV` (เสียงสไลด์กราฟลงฮวบใน iPad)
   * **L6 (Guru Rule):** `Paper Slide.wav` (เสียงปากกาจดลงกระดาษเขียนงบ 5-10%)
   * **L9 (CTA Outro):** `Sonar Glow (F).wav` (เสียงเชื่อม Tonal SFX คีย์ F ดึงเสียงจบคลิปอย่างสมูทมีระดับ)
